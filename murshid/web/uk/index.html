Браузер,
що знає
шлях.

Murshid — це браузер на Chromium, усередині якого живе WebBrain. Запитайте про сторінку перед вами або доручіть їй задачу. Він читає, клацає й друкує у ваших вкладках, поки ви спостерігаєте, і працює на підписках ШІ, за які ви вже платите.

Завантажити Murshid Познайомтеся з WebBrain

Murshid у роботі

Що несе з собою наставник

Повноцінний браузер,
і розум для нього.

Усе, чого ви очікуєте від Chrome, — агент WebBrain вплетається в саму основу, а не прикручується зверху.

#1 Перегляд

Chromium із вкладками

Вкладки, які можна перетягувати й повторно відкривати, адресний рядок, що ще й шукає, завантаження, пошук на сторінці, масштаб, інструменти розробника й скорочення, які ваші руки вже знають.

#2 Питайтесь і дійте

WebBrain у бічній панелі

Запитуйте про будь-яку сторінку, PDF чи виділений текст. Або скажіть, що потрібно зробити, — він заповнить форми, клацне всі кроки й порівне вкладки за вас.

#3 Трей

Ваші підписки на ШІ — з трея

WebBrain Companion працює в системному треї й надає WebBrain ваші підписки Claude, ChatGPT, Gemini, Grok, Kimi, Muse і Devin через 127.0.0.1. Ключі API не потрібні.

#4 Нова вкладка

Нова вкладка, що слухає

Кожна нова вкладка відкривається на сторінці WebBrain: наберіть запитання, задачу чи пошуковий запит — і все потрапить прямо в панель. Вже встановлено й увімкнено.

#5 Локально

Моделі на вашому комп’ютері

Companion може локально запускати Bonsai 2 27B від PrismML і модель рішень WebBrain d1 — підібрані під ваш GPU, перевірені за SHA-256.

#6 Відкритість

Відкрите від початку до кінця

GPL-3.0, розробка відкрита разом із WebBrain. У браузері немає телеметрії. Читайте кожен рядок, що доторкається ваших сторінок.

Шлях

Шукач питає.
Наставник показує.
Потім ви йдете разом.

  1. I

    Запитайте

    Запитайте про сторінку перед вами. WebBrain читає її — текст, таблиці, форми, PDF, навіть те, що є лише на екрані, — і відповідає поруч.

  2. II

    Побачте план

    Для всього, що потребує клацань чи набору тексту, «Plan before Act» (спочатку план, потім дія) спершу розкладає кроки. Затвердьте їх, змініть або зупиніть.

  3. III

    Ідіть

    Потім він працює у ваших справжніх вкладках зі справжніми входами. Кожен його крок видно, і ви будь-коли можете взяти кермо.

Візьміть наставника з собою.

Murshid — це експериментальна версія. Для Windows, macOS і Linux є установники з WebBrain Companion усередині. WebBrain і його сторінка нової вкладки вже встановлені.

Windows

10 та 11, x64. На Arm64 працює з вихідного коду.

Завантажити установник
0.1.0 · x64 · 150 MB

Ще не підписаний кодом, тому Windows SmartScreen може його зупинити: виберіть Додаткові відомості, а потім Усе одно запустити.

macOS

12 Monterey і новіші, Apple Silicon та Intel.

Завантажити установник
0.1.0 · Apple Silicon та Intel · 294 MB

Apple не проходила нотаризацію: клацніть програму правою кнопкою та виберіть Відкрити або скористайтеся Системні налаштування > Конфіденційність і безпека > Усе одно відкрити.

Linux

x64. На Arm64 працює з вихідного коду.

AppImage .deb
0.1.0 · x64 · 171 MB · 135 MB

AppImage: зробіть файл виконуваним і запустіть. У Debian або Ubuntu: sudo apt install ./Murshid-0.1.0-linux-amd64.deb

Джерельний код на GitHub
Запустити з вихідного коду 
git clone --depth 1 --filter=blob:none --sparse -b murshid https://github.com/esokullu/webbrain.git
cd webbrain; git sparse-checkout set murshid src/chrome
cd murshid; npm install; npm start

Лише останній коміт і лише murshid/ з розширенням WebBrain, яке він завантажує: без історії, zip-архівів випусків, відео й тестових файлів.
