Ο φυλλομετρητής
που γνωρίζει
τον δρόμο.

Το Murshid είναι ένας φυλλομετρητής Chromium με μέσα το WebBrain. Ρωτήστε για τη σελίδα που έχετε μπροστά σας ή αναθέστε του μια εργασία. Διαβάζει, κάνει κλικ και πληκτρολογεί στις δικές σας καρτέλες ενώ εσείς παρακολουθείτε, και λειτουργεί με τα πακέτα τεχνητής νοημοσύνης για τα οποία ήδη πληρώνετε.

Το Murshid στη δράση

Όσα κουβαλά ο οδηγός

Ένας πλήρης φυλλομετρητής,
με μυαλό μέσα του.

Όλα όσα περιμένετε από το Chrome, με τον πράκτορα WebBrain πλεγμένο μέσα του και όχι προσαρτημένη προσθήκη.

#1 Περιήγηση

Chromium, με καρτέλες

Καρτέλες που μπορείτε να σύρετε και να ξαναανοίξετε, γραμμή διεύθυνσης που κάνει και αναζητήσεις, λήψεις, εύρεση στη σελίδα, ζουμ, εργαλεία προγραμματιστή και οι συντομεύσεις που τα χέρια σας ήδη γνωρίζουν.

#2 Ρωτήστε & δράστε

WebBrain στον πλευρικό πίνακα

Ρωτήστε για οποιαδήποτε σελίδα, PDF ή επιλογή κειμένου. Ή πείτε του τι θέλετε να γίνει, και αυτό συμπληρώνει τις φόρμες, κάνει κλικ σε κάθε βήμα και συγκρίνει τις καρτέλες για εσάς.

#3 Εικονογείο

Τα πακέτα τεχνητής νοημοσύνης σας, από το εικονογείο

Το WebBrain Companion κάθεται στο εικονογείο του συστήματος και προσφέρει τις συνδρομές σας σε Claude, ChatGPT, Gemini, Grok, Kimi, Muse και Devin στο WebBrain μέσω της διεύθυνσης 127.0.0.1. Χωρίς κλειδιά API.

#4 Νέα καρτέλα

Μια νέα καρτέλα που ακούει

Κάθε νέα καρτέλα ανοίγει στη σελίδα του WebBrain: πληκτρολογήστε μια ερώτηση, μια εργασία ή μια αναζήτηση, και πάει κατευθείαν στον πίνακα. Προεγκατεστημένη και ενεργή.

#5 Τοπικά

Μοντέλα στον ίδιο σας τον υπολογιστή

Το Companion μπορεί να εκτελεί τοπικά το Bonsai 2 27B της PrismML και το μοντέλο απόφασης d1 του WebBrain, προσαρμοσμένο στην κάρτα γραφικών σας, με επαλήθευση SHA-256.

#6 Ανοιχτό

Ανοιχτό, σε κάθε επίπεδο

GPL-3.0, χτισμένο στο φως της δημοσιότητας μαζί με το WebBrain. Χωρίς τηλεμετρία στον φυλλομετρητή. Διαβάστε κάθε γραμμή που ακουμπά τις σελίδες σας.

Ο δρόμος

Ο αναζητητής ρωτά.
Ο οδηγός δείχνει.
Και μετά βαδίζετε μαζί.

  1. I

    Ρωτήστε

    Ρωτήστε για τη σελίδα που έχετε μπροστά σας. Το WebBrain τη διαβάζει — κείμενα, πίνακες, φόρμες, PDF, ακόμα όσα υπάρχουν μόνο στην οθόνη — και απαντά δίπλα της.

  2. II

    Δείτε το σχέδιο

    Για οποιαδήποτε εργασία που περιλαμβάνει κλικ ή πληκτρολόγηση, η προσέγγιση «Plan before Act» παραθέτει πρώτα τα βήματα. Εγκρίνετέ τα, αλλάξτε τα ή σταματήστε.

  3. III

    Βαδίστε

    Έπειτα εργάζεται στις πραγματικές σας καρτέλες, με τις πραγματικές σας συνδέσεις λογαριασμών. Κάθε κίνηση είναι ορατή, και μπορείτε να πάρετε το τιμόνι ανά πάσα στιγμή.

Αποκτήστε το Murshid

Πάρτε τον οδηγό μαζί σας.

Το Murshid είναι αναπτυξιακή προεπισκόπηση. Για Windows, macOS και Linux υπάρχουν εγκαταστάτες με συμπεριλαμβανόμενο το WebBrain Companion. Το WebBrain και η σελίδα νέας καρτέλας του έρχονται προεγκατεστημένα.

Windows

10 και 11, x64. Το Arm64 εκτελείται από την πηγή.

Λήψη εγκαταστάτη
0.1.0 · x64 · 150 MB

Δεν έχει ακόμη υπογραφεί ψηφιακά, γι’ αυτό το Windows SmartScreen μπορεί να το σταματήσει: επιλέξτε Περισσότερες πληροφορίες και έπειτα Εκτέλεση παρόλα αυτά.

macOS

12 Monterey και νεότερες, Apple Silicon και Intel.

Λήψη εγκαταστάτη
0.1.0 · Apple Silicon και Intel · 294 MB

Δεν έχει πιστοποιηθεί από την Apple: κάντε δεξί κλικ στην εφαρμογή και επιλέξτε Άνοιγμα, ή χρησιμοποιήστε το Ρυθμίσεις συστήματος > Απόρρητο και ασφάλεια > Άνοιγμα παρόλα αυτά.

Linux

x64. Το Arm64 εκτελείται από την πηγή.

AppImage .deb
0.1.0 · x64 · 171 MB · 135 MB

AppImage: κάντε το εκτελέσιμο και εκτελέστε το. Σε Debian ή Ubuntu: sudo apt install ./Murshid-0.1.0-linux-amd64.deb

Αθροίσματα ελέγχου SHA-256

Ο πηγαίος κώδικας στο GitHub
Εκτέλεση από την πηγή 
git clone --depth 1 --filter=blob:none --sparse https://github.com/esokullu/webbrain.git
cd webbrain; git sparse-checkout set murshid src/chrome
cd murshid; npm install; npm start

Μόνο το τελευταίο commit, και μόνο ο φάκελος murshid/ με την επέκταση WebBrain που φορτώνει: χωρίς ιστορικό, αρχεία zip εκδόσεων, βίντεο ή αρχεία δοκιμών.

Το Murshid δεν κρατά λίστα ιστορικού περιήγησης. Τα cookies, οι συνδεδεμένοι λογαριασμοί και η αποθήκευση των ιστότοπων διατηρούνται από προεπιλογή, ώστε οι συνεδρίες σας να είναι έτοιμες όταν επιστρέφετε.
