הדפדפן
שיודע
את הדרך.

Murshid הוא דפדפן מבוסס Chromium ובתוכו WebBrain. שאל על הדף שלפניך, או הטל עליו משימה. הוא קורא, לוחץ ומקליד בלשוניות שלך בזמן שאתה צופה, ופועל על תוכניות הבינה המלאכותית שכבר שילמת עליהן.

הורד את Murshid הכר את WebBrain

Murshid בעבודה

מה המדריך נושא עמו

דפדפן שלם,
ובתוכו מחשבה.

כל מה שאתה מצפה מ־Chrome, עם סוכן WebBrain ארוג בתוכו ולא מוברג עליו.

#1 גלישה

Chromium, עם לשוניות

לשוניות שאפשר לגרור ולפתוח מחדש, שורת כתובות שיודעת גם לחפש, הורדות, חיפוש בדף, תקריב, כלי מפתחים וקיצורי המקשים שידיך כבר מכירות.

#2 שאל ופעל

WebBrain בפאנל הצדדי

שאל על כל דף, PDF או קטע מסומן. או אמור לו מה אתה רוצה שייעשה, והוא ימלא טפסים, ילחץ צעד אחר צעד וישווה בין הלשוניות במקומך.

#3 מגש

תוכניות הבינה המלאכותית שלך, מהמגש

WebBrain Companion יושב במגש המערכת ומגיש ל־WebBrain, הכתובת 127.0.0.1, את מנויי Claude, ChatGPT, Gemini, Grok, Kimi, Muse ו־Devin שלך. בלי מפתחות API.

#4 לשונית חדשה

לשונית חדשה שמקשיבה

כל לשונית חדשה נפתחת בדף של WebBrain: הקלד שאלה, משימה או חיפוש, והוא עובר היישר לפאנל. מותקן מראש ופועל.

#5 מקומי

מודלים על המחשב שלך

Companion יכול להריץ מקומית את Bonsai 2 27B של PrismML ואת מודל ההכרעות d1 של WebBrain, בהתאמה לגודל מעבד הגרפי שלך, מאומתים באמצעות SHA-256.

#6 פתוח

פתוח, עד השורה האחרונה

ברישיון GPL-3.0, ונבנה לעיני כל יחד עם WebBrain. בלי טלמטריה בדפדפן. קרא כל שורה שנוגעת בדפים שלך.

הדרך

המבקש שואל.
המדריך מראה.
ואז הולכים יחד.

  1. א

    שאל

    שאל על הדף שלפניך. WebBrain קורא אותו — טקסט, טבלאות, טפסים ו־PDF, ואפילו מה שמופיע רק על המסך — ועונה לצידו.

  2. ב

    ראה את התוכנית

    בכל מה שכרוך בלחיצה או בהקלדה, Plan before Act (תוכנית לפני ביצוע) פורסת את השלבים תחילה. אשר אותם, שנה אותם, או עצור.

  3. ג

    לך

    ואז הוא עובד בלשוניות האמיתיות שלך, עם חשבונות המשתמש האמיתיים שלך. כל תנועה גלויה, ואתה יכול לתפוס את ההגה בכל רגע.

השג את Murshid

קח את המדריך איתך.

Murshid הוא תצוגה מקדימה לפיתוח. ל־Windows, macOS ו־Linux יש מתקינים שכוללים את WebBrain Companion. WebBrain והדף שלו ללשונית חדשה מגיעים מותקנים מראש.

Windows

10 ו־11, x64. Arm64 פועל מהמקור.

הורד את המתקין
0.1.0 · x64 · ‏150 MB

עדיין לא חתום דיגיטלית, לכן Windows SmartScreen עלול לעצור אותו: בחר ב־פרטים נוספים, ואז ב־הפעל בכל זאת.

macOS

12 Monterey ומעלה, Apple Silicon ו־Intel.

הורד את המתקין
0.1.0 · Apple Silicon ו־Intel · ‏294 MB

לא עבר אישור (notarization) של Apple: לחץ לחיצה ימנית על האפליקציה ובחר פתח, או השתמש ב־הגדרות מערכת > פרטיות ואבטחה > פתח בכל זאת.

Linux

x64. Arm64 פועל מהמקור.

AppImage .deb
0.1.0 · x64 · ‏171 MB · 135 MB

AppImage: הפוך אותו לקובץ הרצה והרץ אותו. ב־Debian או Ubuntu: sudo apt install ./Murshid-0.1.0-linux-amd64.deb

סיכומי בדיקה SHA-256

הקוד המקורי ב־GitHub
הרץ מהמקור 
git clone --depth 1 --filter=blob:none --sparse -b murshid https://github.com/esokullu/webbrain.git
cd webbrain; git sparse-checkout set murshid src/chrome
cd murshid; npm install; npm start

ההעלאה העדכנית בלבד, ורק murshid/ והרחבת WebBrain שהיא טוענת: בלי היסטוריית גיטה, בלי קבצי zip של גרסאות, בלי סרטונים ובלי קובצי עזר לבדיקות.
