# DIV 选中文本对话说明

## 为什么“看得见”不等于“模型看得见”

同一个聊天框会保留可见聊天记录，但模型请求还要经过当前作用域筛选。普通聊天会沿用同一标签页的对话记忆；开始一次选中文本问答后，后续请求会遵守这次选区的来源边界。这样可以避免把网页里的恶意指令、旧截图或工具结果误当成新的可信指令。

## 三层状态

| 状态 | 用途 | 是否一定发送给模型 |
| --- | --- | --- |
| 可见 transcript | 让用户阅读、复制和恢复历史 | 否 |
| 对话记忆 | 保存用户/助手轮次，支持普通追问 | 依当前作用域决定 |
| 来源作用域 | 规定本轮允许使用的来源 | 是（以系统提示和筛选后的消息体现） |

自由提问的 `selection_context` 会保留必要的早期用户问题和助手回答，解决“上面提到的三点是什么”等指代。早期助手回答会标记为先前答案，不能当作已验证事实。早期选区原文、工具结果、截图、附件和应用内部消息不会自动带入；当前选区仍以不可信网页数据处理。

固定动作（总结、解释、测验、翻译、校对、Humanize）继续使用严格的 `selection_only`：页面来源仅限当前选区，但可以用模型常识解释选区里出现的术语或概念。

## 用户控制

- 每次选区都会显示作用域分隔线；顶部提示说明当前选区、可用对话和被排除的页面数据。
- 需要引用更早但当前不可见的内容时，先确认“恢复完整对话”。确认只解除作用域，不清空聊天；下一轮才会发送完整对话。
- 不想恢复时，继续在当前选区范围内提问即可；模型可以用常识解释选区里出现的术语，但不要把常识当成页面上的实时事实。需要当前页面或工具时，应说明限制并提示可使用「恢复完整对话」。
- “新对话”会清除消息、选区锚点和持久化作用域。

## 安全边界

网页、截图、下载文件、附件和工具结果都属于不可信数据。恢复完整对话是用户明确的范围选择，不会把网页数据升级成系统指令；恢复后仍保留常规的不可信内容包裹和工具权限检查。

## 验证场景

1. 选中文本 A 并提问，得到回答；再选中文本 B，询问“这三者与上面有什么关系”。确认模型请求保留 A 的用户/助手对话摘要，但不包含 A 的原始页面块。
2. 同一场景切换 Chrome/Firefox、重载面板、重启 Service Worker、重试和压缩上下文；作用域策略保持一致。
3. 点击“恢复完整对话”并确认，下一轮请求才包含完整历史；取消确认时作用域不变。
4. 点击“新对话”，确认可见 transcript、模型对话和作用域全部清空。

Trace 中新增的选区作用域运行时元数据仅记录策略、锚点存在性和排除数量，不记录被筛选的正文或任何指纹。它不会改变 Trace 其他运行、事件、截图、深度调试或无损字段的保留规则；具体内容取决于当前隐私模式。所有 Trace 和诊断导出都应按敏感数据处理。
