Segala sesuatu yang lain terjadi dalam satu panel kecil

Klik ikon untuk membukanya. Satu halaman berisi alamat WebBrain, setiap paket dengan sisa, dan dua model lokal; klik satu baris untuk mengetahui detailnya, atau klik roda gigi untuk pengaturan. Ini mengikuti pengaturan terang atau gelap Anda dan berbicara bahasa Inggris dan Turki.

Bonsai 2 27B, disesuaikan dengan ukuran mesin Anda

Ternary Bonsai 2 27B PrismML mengemas 27 miliar parameter ke dalam 5,95 GB. Pendamping menginstalnya dengan proyektor visi Q8_0 dan versi llama.cpp PrismML, atau sebagai paket MLX di Apple Silicon, dan mencantumkannya di samping langganan Anda sebagai bonsai-2-27b.

Sebelum mengunduh apa pun, ia mengetahui di mana model dijalankan dan apakah masukan gambar cocok. Proyektor vision akan menyala pada GPU ketika tersisa sekitar 1 GB memori GPU setelah model dan konteksnya, pada CPU ketika hanya sistem RAM yang memiliki ruang, dan sebaliknya tetap mati. Anda dapat mengesampingkan pilihan di panel.

Model keputusan WebBrain, di luar browser

Model d1 WebBrain menjawab ya/tidak, pertanyaan pilihan dan skor tentang suatu halaman dan hingga empat tangkapan layar, seperti apakah suatu tugas telah selesai. Pendamping menjalankannya di ONNX Runtime dan menjawab melalui HTTP, sehingga tab browser tidak perlu memuat 1,9 GB. Port Go-nya mengembalikan token dan probabilitas yang sama seperti adaptor JavaScript WebBrain. d1 asli tersedia di Mac Windows, Linux, dan Apple Silicon; itu tidak tersedia di Mac Intel.

Hubungkan WebBrain

Anda melakukan ini sekali. Aplikasi di komputer ini tidak memerlukan kunci API.

  1. Instal pendamping dan buka. Tambahkan langganan di panelnya dan selesaikan proses masuk di browser Anda.
  2. Alamat defaultnya adalah http://127.0.0.1:8327/v1. Jika port berubah, salin alamat yang ditampilkan di panel atau menu baki.
  3. Di WebBrain, buka halaman Providers (Selengkapnya… di menu model panel samping) dan pilih WebBrain Companion. Pertahankan alamat defaultnya kecuali aplikasi menunjukkan port lain. Tidak diperlukan kunci API di komputer ini.
  4. Klik Load Models, pilih model, Save, dan jalankan Test Connection sebelum mengaktifkan kartu. Aktifkan visi hanya untuk model yang menerima gambar.

Klien OpenAI, Anthropic, atau Gemini apa pun di komputer ini dapat menggunakan alamat yang sama. Untuk menggunakannya dari perangkat lain, aktifkan akses jaringan di pengaturan panel; perangkat itu kemudian memerlukan kunci API yang ditampilkan panel.

Unduh

Versi 0.1.3. Setiap paket berisi satu program; pengaturan dan login Anda ada di folder pengguna Anda.

macOS

macOS 12 atau lebih baru, Apple Silicon dan Intel (d1 memerlukan Apple Silicon)

Sistem Anda
  • Aplikasi universal zip, 36 MB

Pindahkan WebBrain Companion ke Aplikasi. Pembuatannya tidak disahkan oleh Apple: pertama kali, izinkan di Pengaturan Sistem, Privasi & Keamanan (Tetap Terbuka). Pada macOS 14 dan versi lebih lama, Control-klik dan pilih Buka.

Windows

Windows 10 dan 11, x64 dan Arm64

Sistem Anda
  • Pemasang setup.exe, 23 MB

Jalankan penginstal: penginstal akan menginstal untuk akun Anda, tanpa perintah administrator, dan menambahkan WebBrain Companion ke menu Mulai. Sampai penginstal ditandatangani dengan kode, SmartScreen mungkin mengatakan "Windows melindungi PC Anda": pilih Info lebih lanjut, lalu Jalankan saja.

Sebelum Anda masuk

Apa yang tersisa di komputer Anda

  • Di komputer ini tidak diperlukan kunci API: pendamping hanya menjawab permintaan dari 127.0.0.1 dan menolak halaman web, sehingga situs yang Anda kunjungi tidak dapat menghabiskan rencana Anda. Ekstensi browser seperti WebBrain dan aplikasi di komputer ini dapat menggunakannya.
  • Perangkat lain hanya dapat terhubung jika Anda mengaktifkan akses jaringan di pengaturan panel. Kemudian mendengarkan pada 0.0.0.0, dan mereka memerlukan kunci API yang ditampilkan panel.
  • Login disimpan di folder pengguna Anda dan hanya dikirim ke penyedianya.
  • Tidak ada analitik. Selain penyedia tempat Anda masuk, ini hanya mengambil daftar model publik CLIProxyAPI, dan, saat Anda menginstal model, filenya dari Hugging Face, GitHub dan, untuk MLX, PyPI.
  • Perintah yang dikirim ke langganan tetap masuk ke penyedia itu. Hanya Bonsai 2 27B dan d1 yang berjalan di mesin Anda.

Apa yang diputuskan oleh penyedia Anda

  • Langganan yang berfungsi melalui proxy tidak sama dengan langganan yang diizinkan oleh penyedia. Persyaratan konsumen Anthropic membatasi akses otomatis di luar kunci API, dan persyaratan Gemini CLI Google menyatakan proses masuknya tidak boleh digunakan dengan alat pihak ketiga.
  • Periksa ketentuan paket dan wilayah Anda sebelum Anda menambahkannya. Jika sebuah akun penting bagi Anda, kunci API penyedia adalah rute yang lebih aman.
  • Matikan akses jaringan pada Wi-Fi publik, dan jangan pernah meneruskan port 8327 ke internet. Kunci API bukanlah keamanan tingkat internet.

Hubungkan WebBrain ke Pendamping

WebBrain Companion adalah perangkat lunak gratis di bawah lisensi GPL-3.0-or-later dan menyematkan CLIProxyAPI. Itu tidak berafiliasi dengan Anthropic, OpenAI, Google, xAI, Moonshot AI, Meta atau Cognition.
