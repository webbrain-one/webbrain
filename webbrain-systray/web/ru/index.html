Bonsai 2 27B, размер соответствует вашей машине

Ternary Bonsai 2 27B PrismML упаковывает 27 миллиардов параметров в 5,95 ГБ. Компаньон устанавливает его вместе с проектором Q8_0 и сборкой llama.cpp для PrismML или как пакет MLX на Apple Silicon и указывает его рядом с вашими подписками как bonsai-2-27b.

Прежде чем что-либо загружается, выясняется, где работает модель и подходит ли входное изображение. Проектор изображения включается на GPU, когда после модели и ее контекста остается около 1 ГБ памяти GPU, на CPU, когда есть место только в системе RAM, и отключается в противном случае. Вы можете отменить выбор на панели.

Модель принятия решений WebBrain вне браузера

Модель d1 WebBrain отвечает на вопросы «да/нет», вопросы выбора и оценки о странице и до четырех снимков экрана, например о том, завершена ли задача. Компаньон запускает его на ONNX Runtime и отвечает по HTTP, поэтому вкладка браузера не должна загружать 1,9 ГБ. Его порт Go возвращает те же токены и вероятности, что и адаптер JavaScript WebBrain. Собственный d1 доступен на компьютерах Mac Windows, Linux и Apple Silicon; он недоступен на компьютерах Mac Intel.

Спросить

curl http://127.0.0.1:8327/companion/v1/decide \
  -H "Content-Type: application/json" \
  -d '{"state": "Order #1042 is confirmed.",
       "questions": {"completion": {
         "type": "choice",
         "instructions": "Did the task finish?",
         "criteria": {"completed": "Confirmed",
                      "not_completed": "Failed or unfinished",
                      "unknown": "Not established"}}}}'

Ответ (273 мс во время выполнения CPU)

{"answers": {"completion": {
   "choice": "completed",
   "confidence": 0.99997,
   "probabilities": {"completed": 0.99997,
                     "not_completed": 0.000002,
                     "unknown": 0.000033}}},
 "diagnostics": {"runtime": "onnxruntime 1.31.0 (CPU)", …}}

Подключить WebBrain

Вы делаете это один раз. Приложениям на этом компьютере не нужен ключ API.

  1. Установите компаньона и откройте его. Добавьте подписку в ее панели и завершите вход в браузере.
  2. Адрес по умолчанию — http://127.0.0.1:8327/v1. Если порт изменился, скопируйте адрес, указанный в меню панели или лотка.
  3. В WebBrain откройте страницу Providers (More… в меню модели боковой панели) и выберите WebBrain Companion. Сохраняйте адрес по умолчанию, если приложение не показывает другой порт. На этом компьютере не требуется ключ API.
  4. Нажмите Загрузить модели, выберите модель Сохранить и запустите Test Connection перед активацией карты. Включайте зрение только для модели, которая принимает изображения.

Любой клиент OpenAI, Anthropic или Gemini на этом компьютере может использовать тот же адрес. Чтобы использовать его с другого устройства, включите доступ к сети в настройках панели; этому устройству затем потребуется ключ API, отображаемый на панели.

Прежде чем войти в систему

Что остается на вашем компьютере

  • На этом компьютере ключ API не требуется: компаньон отвечает только на запросы с адреса 127.0.0.1 и отворачивает веб-страницы, поэтому сайт, который вы посещаете, не может потратить ваши планы. Расширения браузера, такие как WebBrain, и приложения на этом компьютере могут использовать его.
  • Другие устройства смогут подключиться только в том случае, если вы включите доступ к сети в настройках панели. Затем он прослушивает 0.0.0.0, и им нужен ключ API, который отображается на панели.
  • Логины хранятся в вашей пользовательской папке и отправляются только тому провайдеру, которому они принадлежат.
  • Аналитики нет. Помимо поставщиков, к которым вы входите в систему, он получает только общедоступный список моделей CLIProxyAPI, а при установке модели — ее файлы из Hugging Face, GitHub и, для MLX, PyPI.
  • Приглашения, отправленные в подписку, по-прежнему передаются этому поставщику. На вашем компьютере работают только Bonsai 2 27B и d1.

Что решит ваш провайдер

  • Подписка, работающая через прокси, отличается от той, которую разрешает провайдер. Потребительские условия Anthropic ограничивают автоматический доступ за пределами ключа API, а условия Gemini CLI Google гласят, что вход в систему не может использоваться со сторонними инструментами.
  • Прежде чем добавлять его, проверьте условия вашего плана и региона. Если учетная запись имеет для вас значение, ключ API провайдера — более безопасный путь.
  • Отключите доступ к сети общедоступного Wi-Fi и никогда не перенаправляйте порт 8327 в Интернет. Ключ API не обеспечивает безопасность интернет-уровня.
