نموذج محلي، ويب مباشر

امنح نموذج LM Studio طريقتين للوصول إلى الويب.

يضيف WebBrain Web Tools قراءة الروابط العامة إلى أي محادثة في LM Studio تدعم الأدوات. وعند إرفاق امتداد WebBrain، يمكن الإضافة نفسها تفويض هدف إلى ملف Chromium الشخصي الذي سجّلت الدخول إليه بالفعل.

هذه إضافة وليست إعداد MCP

ثبّت webbrain/web-tools من LM Studio Hub. لا تسجّل @webbrain/mcp-server ولا تستخدم منفذ MCP 17374 لهذا المسار؛ فتفويض المتصفح من إضافة LM Studio يستخدم المنفذ 17375.

المسارالأنسب لـما لا يستطيع فعله
fetch_url / research_urlالمقالات العامة والوثائق وواجهات API وJSON والنص وHTML الثابت.لا كوكيز المتصفح، ولا عرض JavaScript، ولا نقر، ولا كتابة، ولا جلسة موثَّقة.
browser_taskلوحات التحكم المسجَّل الدخول إليها، والبريد الويب، والتطبيقات التي تُعرض في العميل، والمهام التي تتطلب تفاعلاً مرئياً في المتصفح.يتطلب WebBrain على Chromium واتصال جسر الإضافة.

قبل التثبيت

المتطلبما يجب التحقق منه
LM Studioافتح تطبيق سطح المكتب الحالي. يمكن لبيئة التشغيل المدمجة لديه تشغيل الإضافات المثبَّتة؛ ولا يلزم تثبيت Node.js بشكل منفصل للاستخدام العادي.
نموذج يدعم الأدواتاستخدم نموذجاً وإعداد محادثة قادرين على استدعاء الأدوات. فالنموذج النصي الصرف الذي لا يدعم الأدوات لن يستدعي الإضافة.
الوصول إلى الشبكةتتواصل أداتا HTTP مع الرابط الذي تطلبه من عملية الإضافة المحلية.
اتصال المتصفح الاختياريبالنسبة إلى browser_task، ثبّت WebBrain في Chrome أو Edge أو Brave أو Opera أو Vivaldi، وأبقِ المنفذ 17375 متاحاً.
مزوّد WebBrain النشطلا تزال مهام المتصفح تعمل عبر المزوّد المهيَّأ داخل امتداد WebBrain.
ابدأ من Hub

تثبيت WebBrain Web Tools وتفعيلها

  1. أبقِ LM Studio مفتوحاً.افتح قائمة webbrain/web-tools في Hub واختر Run in LM Studio. ويمكنك أيضاً فتح الرابط العميق أدناه على الجهاز نفسه.
  2. فعّل الإضافة في المحادثة.افتح عنصر تحكم التكاملات أو الأدوات بجوار حقل إدخال المحادثة، وفعّل webbrain/web-tools.
  3. اختر نموذجاً يدعم الأدوات.توفّر الإضافة أدواتها لهذه المحادثة؛ ويقرّر النموذج متى يستدعيها بناءً على طلبك.
  4. جرّب مسار الويب العام أولاً.اطلب: "اقرأ https://news.ycombinator.com ولخّص الموضوعات الرئيسية في العناوين الحالية." ينبغي أن يستخدم النموذج research_url.
lmstudio://plugin?owner=webbrain&name=web-tools

التثبيت عبر CLI

ينسخ lms clone عنصراً من Hub إلى الدليل الحالي؛ لكنه لا يثبّت هذه النسخة تلقائياً. ادخل إلى الدليل المستنسخ وشغّل صيغة التثبيت من lms dev:

lms clone webbrain/web-tools
cd web-tools
lms dev --install

راجع مرجع lms clone لدى LM Studio ومرجع lms dev --install لسلوك CLI.

ست أدوات، سطحان للثقة

ما تمنحه الإضافة للنموذج

الأداةالاستخدامهل تتطلب امتداد المتصفح؟
fetch_urlيجلب رابط HTTP(S) معروفاً. يتعامل مع JSON وHTML والنص المجرد وترويسات الطلب ومتونه، ويلخّص الاستجابات الثنائية بدل تضمينها مباشرة.لا
research_urlيستخرج نص المقال أو الوثائق القابل للقراءة، مع إزالة عناصر التنقل الشائعة.لا
browser_taskيفوّض هدف Ask أو Act بلغة طبيعية إلى WebBrain في المتصفح المسجَّل الدخول إليه.نعم
browser_statusيفحص اتصال الامتداد، أو يستطلع تشغيلاً قائماً عبر runId.نعم
browser_respondيحوّل جواب المستخدم إلى تشغيل متوقف عند الحالة needs_user_input.نعم
browser_abortيوقف التشغيل الجاري. ولا تُتراجع الإجراءات المكتملة مسبقاً.نعم
الصفحات الطويلة تُضغط ولا تُبتَر ببساطة

عندما يتجاوز الناتج ميزانية الإرجاع، تحتفظ أداتا HTTP بالبداية، ومقاطع وسطية مختارة عالية الدلالة، والنهاية. ويبلغ الناتج المضغوط عن compacted: true ويتضمن بيانات وصفية للضغط. اطلب صفحة أضيق أو زد maxChars عندما يكون المحتوى المحذوف مهماً.

استخدام أداتي HTTP العامة دون متصفح

قراءة مقال معروف

استخدم research_url لقراءة https://example.com/article، وأعطني الأطروحة الرئيسية للكاتب والأدلة الداعمة والقيود المعلنة.

فحص استجابة API

استخدم fetch_url لقراءة https://api.example.com/status. أعد حالة HTTP والحقول التي تدل على صحة الخدمة.

research_url أنسب عادةً لمحتوى المقالات. استخدم fetch_url عندما يهمّ نوع الاستجابة، أو بنية JSON، أو الترويسات، أو الطريقة، أو متن الطلب.

جلب الرابط ليس تبويب متصفح

هذه الطلبات مجهولة ولا تنفّذ JavaScript الصفحة. إذا أبلغ الناتج عن spaSuspected: true، أو كانت الصفحة تتطلب تسجيل دخول، فتوقف عن إعادة محاولة مسار HTTP، واستخدم browser_task بعد توصيل الامتداد.

مسار تسجيل الدخول الاختياري

اربط المتصفح الذي تستخدمه بالفعل

  1. ثبّت WebBrain في متصفح Chromium.يعمل الجسر في Chrome وEdge وBrave وOpera وVivaldi. أما Firefox فلا يمكنه استضافة هذا الاتصال.
  2. فعّل webbrain/web-tools في LM Studio.تفتح الإضافة مستمع الاسترجاع المحلي لديها عند التهيئة.
  3. افتح إعدادات WebBrain.انتقل إلى الإعدادات → Bridge.
  4. اضبط رابط الإضافة ومفتاح الاقتران.أدخل ws://127.0.0.1:17375/extension، والصق المفتاح الموجود في ~/.webbrain/bridge-key (يُنشأ عند بدء تشغيل الإضافة ويُشارك مع خادم MCP) في حقل مفتاح الاقتران، ثم فعّل جسر السحابة.
  5. تحقق من المسار الكامل.اطلب من نموذج LM Studio استدعاء browser_status. فالنتيجة المتصلة تثبت أن مستمع الإضافة ومصافحة الامتداد جاهزان.
لا يمكن الاتصال إلا بوجهة جسر واحدة في كل مرة

لا يملك الامتداد إلا مقبس جسر واحدًا صادرًا. يربطه المنفذ 17375 بهذه الإضافة، ويربطه المنفذ 17374 بخادم MCP، والمنفذ 17373 بـ WebBrain Cloud. تغيير الرابط يبدّل الوجهة، ولا يدمجه.

قد يكون هناك نموذجان معنيان

يقرّر نموذج محادثة LM Studio استدعاء browser_task ويستلم النتيجة. وينفّذ امتداد WebBrain تشغيل المتصفح المفوَّض باستخدام المزوّد النشط المهيَّأ في WebBrain. وإذا كان محتوى الصفحة يجب أن يبقى على الجهاز المحلي، فمهّي مزوّد WebBrain هذا ليستخدم هو الآخر نموذجاً محلياً.

قراءة دون تغيير الصفحة

استخدم browser_task في وضع Ask لقراءة لوحة حسابي المفتوحة بالفعل في متصفحي، وأدر أحدث خمس تنبيهات. لا تغيّر أي شيء.

التفاعل عبر بوابات الإذن

استخدم browser_task في وضع Act لفتح المسودة المعروضة بالفعل في متصفحي، وحدّث اسم الشركة إلى Acme Europe. توقف قبل أي إرسال أو تأكيد نهائي.

دع تشغيلات المتصفح الجارية تستمر

ينتظر browser_task النتيجة، لكن مهلته لا تلغي العمل الجاري بالفعل في الامتداد. احتفظ بـ runId المُعاد، واستخدم أداة الاستعادة المطابقة للحالة.

runningاستطلع باستخدام browser_status
needs_user_inputاسأل، ثم استخدم browser_respond
completedالنتيجة جاهزة
failedاطّلع على الخطأ والأدلة
abortedمتوقف؛ تظل الإجراءات السابقة سارية
  • لا تشغّل browser_task مكرراً بعد انتهاء المهلة؛ استطلع التشغيل القائم.
  • لا تخترع جواباً لأسئلة التوضيح من WebBrain. اسأل المستخدم وانقل جوابه حرفياً.
  • يوقف browser_abort الخطوات اللاحقة. ولا يمكنه التراجع عن نموذج أُرسل، أو رسالة أُرسلت، أو أي إجراء مكتمل آخر.

أبقِ سطحي الثقة واضحين

  • يعمل HTTP العام داخل عملية الإضافة المحلية.يستطيع fetch_url إرسال الطرق والترويسات والمتون، فلا تطلب عملية تغيير إلا إذا قصدتها.
  • تُحظر أهداف الشبكة الخاصة افتراضيًا.تُرفض عناوين الاسترجاع، وRFC1918، والرابط المحلي، وبيانات السحابة الوصفية، وأسماء مضيفات الشبكة الداخلية الشائعة. للوصول إلى localhost أو شبكتك المحلية، فعّل Allow private network access في إعدادات الإضافة في LM Studio، وفي المحادثة التي تحتاجه فقط. لا يستطيع النموذج تفعيله بنفسه، وحتى عند تفعيله تظل نقاط بيانات السحابة الوصفية محجوبة.
  • يُعاد فحص إعادة التوجيه.تتحقق الإضافة من كل وجهة، وتزيل الترويسات الشبيهة بالبيانات التعريفية عند عبور إعادة التوجيه لأصول مختلفة.
  • يبقى مستمع المتصفح على الاسترجاع المحلي.لا تحوّل أو توكّل المنفذ 17375 أبدًا. تعرّف مصافحةُ الامتداد العميل لكنها ليست مصادقة بسر مشترك؛ تعامل البرمجيات المحلية على أنها موثوقة.
  • وضع Ask هو الخيار الافتراضي.استخدم Act فقط عندما تتطلب النتيجة المطلوبة تفاعلاً مرئياً في المتصفح، وأبقِ المتصفح في نطاق يمكنك فيه إيقاف السلوك غير المتوقع.
  • يستطيع نموذج LM Studio رؤية نتائج الأدوات.ويرسل تشغيل المتصفح أيضًا سياق المهمة عبر المزوّد النشط المهيَّأ في WebBrain. اختر حدود النموذجين بعناية.

للتفاصيل على مستوى التنفيذ، بما في ذلك كيفية تثبيت كل اتصال على العنوان الذي تم فحصه، اقرأ ملاحظات الأمان الخاصة بالإضافة.

استكشاف الأخطاء حسب العَرَض

العَرَضما يعنيه عادةًالحل
لا تظهر الأدواتالإضافة غير مفعَّلة لهذه المحادثة، أو النموذج المحدد لا يستطيع استدعاء الأدوات.فعّل webbrain/web-tools بجوار حقل الإدخال، واختر نموذجاً يدعم الأدوات.
يبلغ browser_status عن انقطاع الاتصالالإضافة متاحة، لكن امتداد WebBrain لم يتصل بعد.استخدم Chromium، وفعّل جسر السحابة، وأدخل بالضبط ws://127.0.0.1:17375/extension.
لا يستطيع المستمع البدء أو يبلغ عن تعارض في العنواننسخة أخرى من الإضافة أو عملية أخرى تشغل المنفذ 17375 بالفعل.أغلق النسخة المكررة ثم أعد تحميل الإضافة. وتحقق أولاً باستخدام lsof -nP -iTCP:17375 -sTCP:LISTEN.
صفحة عامة فارغةتُعرض الصفحة باستخدام JavaScript أو تخفي المحتوى خلف تسجيل الدخول.إذا كانت spaSuspected صحيحة، فوصّل الامتداد واستخدم browser_task.
انتهت مهلة المهمة لكن المتصفح لا يزال يعملنفدت ميزانية الانتظار، لكن تشغيل WebBrain لم يُلغَ.استدعِ browser_status باستخدام runId المُعاد، أو browser_abort إذا أردت الإيقاف.
لا يتصل Firefox أبدًالا يملك Firefox بيئة تشغيل لجسر المستندات خارج الشاشة.استخدم متصفح Chromium لأدوات المتصفح. وأداتا HTTP العامتان تعملان دون امتداد.
انقطع اتصال MCP أو WebBrain Cloudاستبدل رابط LM Studio وجهة الجسر الوحيدة للامتداد.بعد الانتهاء، أعد الإعدادات إلى المنفذ 17374 (MCP) أو 17373 (WebBrain Cloud).
