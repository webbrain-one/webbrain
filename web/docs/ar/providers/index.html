النموذج خلف اللوحة

اختر الإعداد الذي يناسب صبرك واحتياجات خصوصيتك وميزانيتك.

يضم WebBrain 114 بطاقة مزوّد تغطي الخدمات السحابية المستضافة وواجهات API السحابية المباشرة وموجّهات النماذج والخوادم المحلية المتوافقة مع OpenAI. لا تحتاج سوى مزوّد نشط واحد.

موجّه النماذج

بدّل بين نماذج كثيرة بحساب واحد؛ يناسب من يجربون كثيرًا.

114 بطاقة مزوّد مدمجة

تضيف صفحة المزوّدين 79 واجهة API مباشرة وموجّهات، منها Azure AI Foundry وVertex AI وVertex Anthropic وCerebras وCohere وDeepInfra وPerplexity وVercel AI Gateway وVenice وباقات برمجة إقليمية عديدة. يمكنك البحث باسم المزوّد أو النموذج.

تستخدم معظم البطاقات مفتاح API ونقطة نهاية متوافقة مع OpenAI. تستخدم بطاقات Vertex مشروع Google Cloud والمنطقة ومفتاح التفويض؛ تستخدم المنطقة العالمية نقطة نهاية Google العالمية، بينما تدعم Vertex Anthropic أيضًا مضيفي المناطق المتعددة us وeu. يقبل Cloudflare معرّف AI Gateway اختياريًا؛ ولنماذج @cf/ تُستخدم بوابة default تلقائيًا عند ترك الحقل فارغًا. تعرض المزوّدة الدفقية الردود في الوقت الحقيقي ضمن Ask التفاعلي، وتعيد المحاولة تلقائيًا مرة واحدة دون تدفق عند انتهاء الاتصال قبل الأوان. وعندما تُرجع الخدمة استهلاك الرموز، يُسجَّل مباشرة؛ وإلا يسجل WebBrain تقديرًا متحفظًا حتى لا تتجاوز الطلبات الدفقية حدود التكلفة.

غياب إدخالات GitHub مقصود

لن يختفي GitHub بحد ذاته، لكن GitHub Models سيُتقاعد في 30 يوليو 2026. يتطلب GitHub Copilot اشتراكًا أو تكامل OAuth منفصلًا. كما يتطلب GitLab Duo وSAP AI Core مصادقة واكتشافًا خاصين للنشر لا تدعمهما إضافة المتصفح.

خطوات الإعداد

  1. افتح صفحة المزوّدين. اختر المزيد… في قائمة النماذج بالشريط الجانبي، أو رابط «المزوّدين» أعلى صفحة الإعدادات. يعرض تبويب LLM مزوّدي المحادثة.
  2. اعثر على المزوّد. استخدم «محلي» أو «سحابي» أو «موجّه» أو مربع البحث.
  3. وسّع البطاقة وأدخل القيم. تتطلب الخوادم المحلية عادةً العنوان واسم النموذج؛ وتحتاج المزوّدة السحابية أيضًا مفتاح API.
  4. احفظ. يكتب الحقول الحالية في المتصفح.
  5. اختبر الاتصال. أصلح أولًا أخطاء العنوان أو المفتاح أو النموذج أو الخادم.
  6. اجعله نشطًا. بعد نجاح الاختبار فقط. الحفظ لا يعني التفعيل.

معاني الحقول

الحقلالمعنىنصيحة
الخادم / Base URLنقطة الجذر المتوافقة مع OpenAI أو جذر API المزوّد.استخدم القيمة الدقيقة التي يعرضها تطبيقك المحلي أو مزوّدك، ولا تلصق عنوان صفحة محادثة.
مفتاح APIالبيان المُرسَل إلى المزوّد للمصادقة.لا تحتاجه الخوادم المحلية عادةً إلا إذا فعّلت المصادقة بنفسك.
النموذجمعرّف النموذج الذي يطلبه الخادم.يجب أن تطابق حالة الأحرف والبادئات والهجاء تمامًا.
نافذة السياقالكمية التي تتسع لها الطلبية الواحدة من المطالبة والسجل ومحتوى الصفحة ومخططات الأدوات.يُنصح بـ 16k على الأقل للتشغيل المحلي الموثوق؛ و8k قد تعمل مع Compact؛ أما 4k فقليلة جدًا.
دعم الرؤيةهل يقبل النموذج الحالي الصور؟فعّل هذا فقط عندما تتأكد أن النموذج المُقدَّم يدعم الصور.
مستوى المطالبةطول المطالبة ونطاق أدوات المتصفح الاعتيادية التي يعرضها WebBrain.ابدأ بـ Mid للنماذج المحلية؛ وCompact للسياقات الصغيرة، وFull للنماذج القوية.

مستويات المطالبة

Compactأقصر مطالبة وأصغر سطح أدوات، يناسب النماذج المحلية الصغيرة ذات سياقات نحو 8k.
Midيشمل مهام المتصفح الاعتيادية وiframe والتنزيلات والمهام المجدولة والتحقق من النماذج. نقطة البداية المحلية الموصى بها.
Fullيضيف أدوات ارتداد متقدمة مثل التمرير hover والسحب والإفلات والإطارات وShadow DOM.

تستخدم المزوّدة السحابية Full دائمًا؛ والمحلية Mid افتراضيًا؛ ولا تستطيع مزوّدة Compact استخدام وضع Dev.

عند فشل اختبار الاتصال

  1. Connection refused:شغّل الخادم المحلي وتأكد من المنفذ.
  2. CORS/Origin:اسمح لمصدر إضافة WebBrain في الخادم.
  3. Unauthorized:تأكد أن المفتاح وBase URL يعودان إلى المزوّد نفسه.
  4. Model not found:انسخ معرّف النموذج بدقة، أو استخدم Load models.
  5. انتهاء المهلة:ارفع مهلة طلبات LLM في «الإعدادات → الميزانيات» للنماذج المحلية الكبيرة التي تعمل على المعالج.
  6. الفشل بعد بضع جولات:تحقق من نافذة السياق الحقيقية، وخفض مستوى المطالبة أو وسّع سياق النموذج.

النماذج المساعدة الاختيارية

يتولى المزوّد الحالي المحادثة الأساسية والتخطيط والردود النهائية. تتيح التبويبات الأخرى في صفحة المزوّدين إعدادًا مستقلًا لنموذج الرؤية، ونقطة نهاية الكلام (تحويل الكلام إلى نص)، ووسائل التوليد، ونماذج اتخاذ القرار، وSafeSocial. ولا تتأثر هذه الإعدادات بترشيح المزوّدين أو تبديلهم.

نماذج الرؤية واتخاذ القرار على تلقائي افتراضيًا: في Chrome يُستخدم Compass VLD v6 2B بعد اكتمال تنزيله (أو Compass VLD Tiny v5 السابق إذا كان هو المنزَّل وحده؛ وإذا غابا وكان المنزل Ternary Bonsai 2 2B Vision أو D1، يقرأ الأول لقطات الشاشة ويجيب الثاني عن القرارات؛ وعندما يكون WebBrain Cloud نشطًا، يتولى نموذج القرار المُدار لدى Compass القرارات)، ولا يُستخدم شيء قبل التنزيل. لا يجيب نموذج القرار إلا عن أسئلة نعم/لا والخيار المتعدد مثل «هل اكتملت هذه المهمة؟»؛ اختر تشغيل ليجيب OpenRouter أو TypeSafe أو خادم محلي أو D1 أو نموذج المتصفح عن كل القرارات، أو إيقاف لعدم الاستخدام مطلقًا. وتنطبق الأذونات وفحوصات الإكمال القائمة كما هي. راجع نماذج الرؤية والكلام واتخاذ القرار لطريقة الإعداد ومشاركة البيانات.
