Dokumentasi / Penyedia dan model
Model di balik panel

Pilih pengaturan yang sesuai dengan kesabaran, kebutuhan privasi, dan anggaran Anda.

WebBrain menyertakan 114 kartu penyedia, mencakup layanan cloud terkelola, API cloud langsung, router model, dan server OpenAI-kompatibel lokal. Anda hanya perlu satu penyedia aktif.

Pilihan cepat

Paling sedikit langkah

WebBrain Compass

Sudah terpasang, aktif secara default, termasuk kuota gratis harian; tanpa server model atau kunci API.

Privasi dan kemampuan luring

Model lokal

Gunakan llama.cpp, Ollama, ODS, LM Studio, Jan, vLLM, SGLang, atau LocalAI.

Langsung dari vendor

API cloud

Isi kunci Anda sendiri untuk OpenAI, Anthropic, Gemini, Mistral, DeepSeek, xAI, Groq, dan penyedia yang didukung lainnya.

Katalog model luas

Router model

Beralih di antara banyak model dengan satu akun; cocok bagi yang sering bereksperimen.

114 kartu penyedia bawaan

Bagian LLM di Pengaturan menambahkan 79 API langsung dan router, termasuk Azure AI Foundry, Vertex AI, Vertex Anthropic, Cerebras, Cohere, DeepInfra, Perplexity, Vercel AI Gateway, Venice, dan banyak paket pemrograman regional. Cari berdasarkan nama penyedia atau model.

Sebagian besar kartu menggunakan kunci API dan endpoint OpenAI-kompatibel. Kartu Vertex menggunakan proyek Google Cloud, wilayah, dan kunci otorisasi; wilayah global memakai endpoint global Google, dan Vertex Anthropic juga mendukung host multi-wilayah us dan eu. Cloudflare menerima ID AI Gateway opsional; untuk model @cf/, jika kolom dikosongkan, gateway default dipakai otomatis. Penyedia yang mendukung streaming menampilkan balasan secara langsung di Ask interaktif, dan saat koneksi terputus lebih awal, otomatis mencoba sekali lagi tanpa streaming. Ketika layanan mengembalikan pemakaian token, hal itu dicatat langsung; jika tidak, WebBrain mencatat estimasi konservatif agar permintaan streaming tidak melewati batas biaya.

Entri GitHub sengaja tidak disediakan

GitHub sendiri tidak akan tutup, tetapi GitHub Models pensiun pada 30 Juli 2026. GitHub Copilot memerlukan langganan atau integrasi OAuth terpisah. GitLab Duo dan SAP AI Core juga memerlukan autentikasi khusus dan penemuan deployment yang tidak didukung ekstensi peramban.

Langkah penyiapan

  1. Buka Pengaturan → Model → LLM. Pilih Lainnya… di menu model panel samping, atau pilih LLM di bawah Model pada bilah samping Pengaturan. Bagian itu mencantumkan penyedia chat.
  2. Temukan penyedia. Gunakan “Lokal”, “Cloud”, “Router”, atau kotak pencarian.
  3. Bentangkan kartu dan isi nilainya. Server lokal biasanya memerlukan alamat dan nama model; penyedia cloud juga memerlukan kunci API.
  4. Simpan. Menulis kolom saat ini ke peramban.
  5. Uji koneksi. Perbaiki kesalahan alamat, kunci, model, atau server terlebih dahulu.
  6. Jadikan aktif. Beralih hanya setelah uji berhasil. Menyimpan tidak berarti sudah diaktifkan.

Koneksi ditolak biasanya berarti server belum berjalan atau port salah; galat CORS/Origin memerlukan izin asal ekstensi peramban. Umum untuk Ollama: OLLAMA_ORIGINS="chrome-extension://*,moz-extension://*" ollama serve.

Level prompt

CompactPrompt terpendek dan permukaan tool terkecil, cocok untuk model lokal kecil dengan konteks sekitar 8k.
MidMenyertakan tugas peramban umum, iframe, unduhan, tugas terjadwal, dan validasi formulir. Titik awal lokal yang disarankan.
FullMenambahkan tool fallback lanjutan seperti hover, seret-lepas, frame, dan Shadow DOM.

Penyedia cloud tetap memakai Full; penyedia lokal default Mid; penyedia Compact tidak dapat memakai mode Dev.

Saat uji koneksi gagal

  1. Connection refused: Jalankan server lokal dan pastikan port.
  2. CORS/Origin: Izinkan asal ekstensi WebBrain di server.
  3. Unauthorized: Pastikan kunci dan Base URL milik penyedia yang sama.
  4. Model not found: Salin ID model persis, atau gunakan Load models.
  5. Waktu habis: Naikkan batas waktu permintaan LLM di “Pengaturan → Anggaran” untuk model CPU lokal besar.
  6. Gagal setelah beberapa giliran: Pastikan jendela konteks sebenarnya; turunkan level prompt atau perbesar konteks model.

Model bantu opsional

Penyedia aktif menangani percakapan utama, perencanaan, dan balasan akhir. Entri lain di bawah Model pada Pengaturan dapat mengonfigurasi secara terpisah model Visi, endpoint Ucapan (suara ke teks), media Generatif, model Keputusan, dan SafeSocial. Pengaturan ini tidak terpengaruh oleh filter atau pergantian penyedia.

Model Vision dan Decision secara default berada di Auto: di Chrome, Compass VLD v6 2B dipakai setelah selesai diunduh (Compass VLD Tiny v5 jika hanya itu yang diunduh; jika keduanya tidak ada dan hanya Ternary Bonsai 2 2B Vision atau D1 yang diunduh, yang pertama membaca tangkapan layar dan yang kedua menangani keputusan; saat WebBrain Cloud aktif, keputusan ditangani model keputusan terkelola Compass), dan tidak ada sebelum unduhan. Model keputusan hanya menjawab ya/tidak dan pilihan ganda seperti “Sudah selesai tugas ini?”; pilih On agar OpenRouter, TypeSafe, server lokal, D1, atau model dalam peramban menjawab semua keputusan, atau Off untuk tidak pernah memakainya. Izin dan pemeriksaan penyelesaian yang ada tetap berlaku. Cara konfigurasi dan pembagian data lihat Model visi, suara, dan keputusan.
