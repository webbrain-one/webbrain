Buku Pegangan WebBrain

Agen peramban Anda punya banyak pengaturan, tetapi Anda tidak perlu mempelajari semuanya terlebih dahulu.

Buka sebuah halaman web dan ajukan pertanyaan. Panduan ini menuntun Anda ke hasil lewat jalur terpendek, lalu menjelaskan pengaturan yang lebih dalam hanya saat benar-benar diperlukan.

Penggunaan Pertama

Selesaikan satu tugas dulu

Buka panel samping, pilih mode yang tepat, dan mulai tanpa mengubah pengaturan apa pun.

Mulai menggunakan →Kendalikan Agen

Pahami Pengaturan

Apa yang diubah setiap tab, nilai bawaan mana yang cocok untuk kebanyakan orang, dan mana yang bisa diabaikan dulu.

Buka panduan pengaturan →Pilih Model

Konfigurasi Penyedia

Gunakan WebBrain Compass, API cloud, perutean model, atau model lokal.

Pilih model →Tetap Terkendali

Gunakan mode Eksekusi dengan aman

Pelajari mode Tanya, Eksekusi, dan Dev, izin situs, batas memori, dan penimpaan berisiko tinggi.

Lihat panduan keamanan →Pindahkan Konten

Ekspor dengan tenang

Bedakan file percakapan, jejak, pengaturan, dan alur kerja tersimpan, serta pahami mana yang sensitif.

Pelajari format ekspor →
Jalankan Pertama Kali

10 menit pertama

  1. Buka halaman web yang ingin Anda kerjakan. Klik ikon WebBrain agar panel samping tampil berdampingan dengan halaman.
  2. Tetap di mode Tanya terlebih dahulu. Misalnya: "Ringkas halaman ini", "Daftar tanggal penting", "Bandingkan paket dalam tabel ini". Mode Tanya dapat membaca, tetapi tidak mengeklik atau mengetik.
  3. Beralih ke Eksekusi saat halaman perlu diubah. Misalnya: "Ketik wireless headphones di kolom pencarian lalu cari". Sebelum tindakan penting di situs baru, WebBrain meminta izin.
  4. Perhatikan prosesnya. Hentikan kapan saja dengan tombol Stop atau Escape. Segera hentikan jika terjadi navigasi, ketikan, atau tindakan berulang yang tak terduga.
  5. Buka Pengaturan hanya saat memang perlu. Penyedia cloud bawaan dan nilai keamanan bawaan yang disarankan cukup untuk menyelesaikan tugas pertama.
Prompt yang baik menuliskan hasilnya

"Temukan kebijakan pengembalian dana dan beri tahu apakah berlaku untuk produk promo" lebih mudah diverifikasi daripada "lihat-lihat situs ini". Tuliskan tujuannya dan batas yang tidak boleh dilewati WebBrain.

Pilih mode dulu, baru kirim prompt

Eksekusi ActMengklik, mengetik, menavigasi, mengunduh, menjadwalkan tugas.
Kembangkan DevMenambahkan alat kode sumber, gaya, DOM, frame, dan debugging.
Ini peta, bukan daftar periksa

Pengaturan sekilas

Anda tidak perlu mengonfigurasi semuanya. Penyedia dan Izin punya halaman sendiri; sisanya adalah tab di Pengaturan, plus "Skills", "CAPTCHA", dan "Bridge" untuk fitur tambahan tertentu. Warna di bagian bawah setiap kotak menunjukkan seberapa sering pengguna biasa membutuhkannya.

Batas keamanan

Pertahankan "Rencanakan sebelum Eksekusi" pada "Coba rencanakan", biarkan peninjauan rencana memakai ambang keyakinan, biarkan konfirmasi tugas terjadwal tetap aktif, dan "Tanya sebelum tindakan penting" tetap aktif. Opsi lain boleh tidak diubah dulu.
