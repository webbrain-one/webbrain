Model lokal, persetujuan terlihat

Pilih model di Ollama. Gunakan di dalam WebBrain.

WebBrain saat ini dapat menggunakan endpoint OpenAI-kompatibel lokal milik Ollama. Konfigurasikan di Pengaturan dengan rilis Ollama resmi, atau coba serah terima peluncuran pratinjau yang mengirim model, endpoint, dan jendela konteks ke WebBrain untuk persetujuan sekali klik.

Perintah peluncuran masih dalam tahap pratinjau

ollama launch webbrain belum termasuk dalam build Ollama upstream. Jalur Pengaturan biasa berfungsi dengan rilis resmi; serah terima satu perintah saat ini memerlukan cabang pratinjau yang ditautkan.

Dua jalur pemasangan

JalurGunakan ketikaLangkah Anda

Berfungsi dengan Ollama upstream

Konfigurasikan rilis Ollama resmi secara manual

  1. Instal Ollama dan tarik model yang mumpuni.Pilih model yang secara andal menjalankan panggilan tool. Run agen memerlukan jendela konteks minimal 16k token.
  2. Izinkan origin ekstensi browser.Jika proses desktop Ollama lain sudah menempati port 11434, hentikan proses itu terlebih dahulu, lalu jalankan server dari terminal dengan daftar izin origin di bawah.
  3. Buka halaman Penyedia WebBrain.Pilih Lainnya… di menu model di bilah samping, temukan Ollama (Local) di tab LLM, lalu buka kartunya.
  4. Masukkan endpoint dan model.Gunakan http://localhost:11434/v1, lalu pilih model yang Anda tarik.
  5. Simpan dan uji koneksi.Gunakan Muat model agar WebBrain membaca ID model yang tersedia dan mendeteksi jendela konteks langsung.
  6. Jadikan aktif.Mulai dari tingkatan prompt Mid. Gunakan Compact hanya ketika konteks model terbatas.
ollama pull <model>
OLLAMA_ORIGINS="chrome-extension://*,moz-extension://*" ollama serve
Permintaan terminal bisa berhasil tetapi WebBrain mendapat 403

curl tidak mengirim origin ekstensi browser. Jika Ollama berfungsi di terminal tetapi gagal di WebBrain, restart server Ollama dengan OLLAMA_ORIGINS, bukan mengubah URL penyedia.

Pratinjau · lebih sedikit pengaturan

Coba serah terima peluncuran Ollama

Perintah pratinjau membuka URL peluncuran WebBrain yang berisi model terpilih, endpoint loopback /v1 lokal, dan jendela konteks yang terdeteksi. Ekstensi menampilkan nilai-nilai itu dalam dialog konfirmasi sebelum melakukan perubahan apa pun.

git clone https://github.com/esokullu/ollama.git
cd ollama
git switch codex/ollama-webbrain-launch-handoff
cmake -S . -B build -G Ninja -DOLLAMA_MLX_BACKENDS=
cmake --build build --parallel 8

OLLAMA_ORIGINS="chrome-extension://*,moz-extension://*" ./ollama serve

Biarkan server tetap berjalan. Di terminal lain, ganti model contoh dengan model yang tersedia di instalasi Ollama lokal Anda:

./ollama launch webbrain --model qwen3.5:9b
  1. Biarkan perintah membuka webbrain.one.Ekstensi hanya menerima serah terima ini di halaman peluncuran Ollama WebBrain.
  2. Tinjau konfirmasi.Periksa model, URL penyedia loopback lokal, dan jendela konteks.
  3. Setujui perubahan.WebBrain memperbarui penyedia Ollama lokal dan menjadikannya aktif.
  4. Buka bilah samping.Penyedia aktif seharusnya tampil sebagai Ollama (Local).
Serah terima tetap lokal

WebBrain hanya menerima host Ollama loopback lokal, URL HTTP(S) tanpa kredensial tertanam, dan endpoint /v1 yang kompatibel dengan OpenAI. Nama model dan jendela konteks dinormalisasi sebelum penyedia disimpan.

Pilih model dan konteks yang dapat menggerakkan agen

  • Mulai dari konteks 16k atau lebih.Itu adalah minimum praktis untuk prompt sistem, tool browser, konten halaman, dan riwayat percakapan yang berguna.
  • Pelatihan penggunaan tool itu penting.Model yang menjawab obrolan biasa dengan baik tetap dapat menghasilkan panggilan tool yang tidak valid atau hilang.
  • Gunakan Mid terlebih dahulu.Mode ini mengekspos set tool browser umum dengan biaya prompt yang lebih rendah. Compact dapat membantu di sekitar 8k; 4k terlalu kecil untuk berjalan secara andal.
  • Kemampuan vision berbeda-beda per model.Aktifkan vision hanya jika model Ollama yang Anda sajikan menerima gambar.
  • Uji model langsung.Uji koneksi dan Muat model dapat membaca informasi runtime Ollama dan menyegarkan jendela konteks yang terdeteksi.

Atasi masalah berdasarkan gejala

GejalaPenyebab yang mungkinSolusi
WebBrain melaporkan 403Ollama menolak origin ekstensi.Restart server dengan OLLAMA_ORIGINS="chrome-extension://*,moz-extension://*".
Koneksi ditolakOllama berhenti, atau WebBrain menggunakan port yang salah.Jalankan ollama serve dan tetap gunakan URL dasar http://localhost:11434/v1.
Model tidak ditemukanID model yang disimpan tidak cocok persis dengan katalog Ollama.Jalankan ollama list atau gunakan Muat model, lalu salin nama model lengkap (termasuk tag).
Model hanya mengobrol tanpa memakai tool browserModel lemah dalam penggunaan tool, atau tingkatan konteks/prompt terlalu terbatas.Coba model terlatih tool, tingkatkan konteks, atau beralih dari Compact ke Mid.
Perintah tidak dikenal: ollama launchAnda menjalankan build Ollama upstream.Gunakan pengaturan penyedia manual, atau bangun cabang pratinjau yang ditautkan.
Halaman peluncuran terbuka tetapi tidak ada promptEkstensi WebBrain tidak ada, dinonaktifkan, atau sudah usang.Aktifkan ekstensi saat ini di webbrain.one, muat ulang halaman peluncuran, lalu jalankan perintah lagi.
