Model lokal, web langsung

Beri model LM Studio dua cara untuk mengakses web.

WebBrain Web Tools menambahkan pembacaan URL publik ke chat LM Studio mana pun yang mendukung alat. Saat ekstensi WebBrain dilampirkan, plugin yang sama juga dapat mendelegasikan tujuan ke profil Chromium tempat Anda sudah masuk.

Ini plugin, bukan pengaturan MCP

Pasang webbrain/web-tools dari LM Studio Hub. Jangan daftarkan @webbrain/mcp-server atau gunakan port MCP 17374 untuk jalur ini; delegasi peramban dari plugin LM Studio menggunakan port 17375.

Mulai dari Hub

Memasang dan mengaktifkan WebBrain Web Tools

  1. Biarkan LM Studio terbuka. Buka daftar Hub webbrain/web-tools dan pilih Run in LM Studio. Anda juga dapat membuka deep link di bawah ini di mesin yang sama.
  2. Aktifkan plugin di dalam chat. Buka kontrol integrasi atau alat di samping input chat dan nyalakan webbrain/web-tools.
  3. Pilih model yang mendukung alat. Plugin menawarkan alatnya ke chat itu; model memutuskan kapan memanggilnya berdasarkan permintaan Anda.
  4. Coba jalur web publik terlebih dahulu. Tanyakan: "Baca https://news.ycombinator.com dan ringkas tema utama judul berita saat ini." Model seharusnya menggunakan research_url.
lmstudio://plugin?owner=webbrain&name=web-tools

Pemasangan CLI

lms clone menyalin artefak Hub ke direktori saat ini; salinan itu tidak otomatis terpasang. Masuk ke direktori hasil clone dan jalankan bentuk instalasi lms dev:

lms clone webbrain/web-tools
cd web-tools
lms dev --install

Lihat referensi lms clone dan referensi lms dev --install LM Studio terkini untuk perilaku CLI.

Halaman panjang dipadatkan, bukan sekadar dipotong

Ketika hasil melebihi anggaran pengembalian, alat HTTP menyimpan bagian awal, bagian tengah bersinyal tinggi yang dipilih, dan bagian akhir. Hasil yang dipadatkan melaporkan compacted: true dan menyertakan metadata pemadatan. Minta halaman yang lebih sempit atau tingkatkan maxChars ketika konten yang dihilangkan penting.

Menggunakan alat HTTP publik tanpa peramban

Membaca artikel yang diketahui

Gunakan research_url untuk membaca https://example.com/article dan berikan argumen utama penulis, bukti pendukung, dan keterbatasan yang dinyatakan.

Memeriksa respons API

Gunakan fetch_url untuk membaca https://api.example.com/status. Kembalikan status HTTP dan bidang yang menunjukkan kesehatan layanan.

research_url biasanya pilihan yang lebih baik untuk prosa. Gunakan fetch_url ketika tipe respons, struktur JSON, header, metode, atau body penting.

Ambil URL bukan tab peramban

Permintaan ini anonim dan tidak menjalankan JavaScript halaman. Jika hasil melaporkan spaSuspected: true, atau halaman memerlukan login, hentikan percobaan ulang jalur HTTP dan gunakan browser_task setelah menghubungkan ekstensi.

Jalur masuk opsional

Hubungkan peramban yang sudah Anda gunakan

  1. Pasang WebBrain di peramban Chromium. Jembatan berfungsi di Chrome, Edge, Brave, Opera, dan Vivaldi. Firefox tidak dapat menampung koneksi ini.
  2. Aktifkan webbrain/web-tools di LM Studio. Plugin membuka listener loopback lokalnya saat diinisiasi.
  3. Buka Pengaturan WebBrain. Masuk ke Pengaturan → Bridge.
  4. Atur URL plugin dan kunci pasangan. Masukkan ws://127.0.0.1:17375/extension, tempelkan kunci dari ~/.webbrain/bridge-key (dibuat saat plugin dimulai; dibagi dengan server MCP) ke kolom Kunci pasangan, lalu aktifkan jembatan cloud.
  5. Verifikasi jalur lengkap. Minta model LM Studio memanggil browser_status. Hasil terhubung membuktikan listener plugin dan jabat tangan ekstensi siap.
Hanya satu tujuan jembatan pada satu waktu

Ekstensi hanya memiliki satu socket jembatan keluar. Port 17375 menghubungkannya ke plugin ini, port 17374 ke server MCP, dan port 17373 ke WebBrain Cloud. Mengubah URL berpindah tujuan; tidak menggabungkannya.

Dua model mungkin terlibat

Model chat LM Studio memutuskan memanggil browser_task dan menerima hasilnya. Ekstensi WebBrain menjalankan operasi peramban yang didelegasikan melalui penyedia aktif yang dikonfigurasi di dalam WebBrain. Jika konten halaman harus tetap di perangkat, konfigurasikan penyedia WebBrain itu juga untuk menggunakan model lokal.

Membaca tanpa mengubah halaman

Gunakan browser_task dalam mode Ask untuk membaca dasbor akun yang sudah terbuka di peramban saya dan daftar lima peringatan terbaru. Jangan ubah apa pun.

Interaksi melalui gerbang izin

Gunakan browser_task dalam mode Act untuk membuka draf yang sudah tampil di peramban saya dan perbarui nama perusahaan menjadi Acme Europe. Berhenti sebelum pengiriman atau konfirmasi akhir apa pun.

Biarkan run peramban yang berjalan terus berlanjut

browser_task menunggu hasil, tetapi timeout-nya tidak membatalkan pekerjaan yang sudah berjalan di ekstensi. Simpan runId yang dikembalikan dan gunakan alat pemulihan yang cocok dengan statusnya.

runningPantau dengan browser_status
needs_user_inputTanya, lalu gunakan browser_respond
completedHasil siap
failedLihat kesalahan dan bukti
abortedBerhenti; aksi sebelumnya tetap berlaku
  • Jangan memulai browser_task duplikat setelah timeout; pantau run yang ada.
  • Jangan pernah mengarang jawaban untuk pertanyaan klarifikasi WebBrain. Tanyakan kepada pengguna dan teruskan jawaban mereka secara verbatim.
  • browser_abort menghentikan langkah selanjutnya. Ia tidak dapat membatalkan formulir yang dikirim, pesan yang terkirim, atau aksi selesai lainnya.

Jaga dua permukaan kepercayaan tetap jelas

  • HTTP publik berjalan di proses plugin lokal. fetch_url dapat mengirim metode, header, dan body, jadi hanya minta perubahan ketika Anda memang menginginkannya.
  • Tujuan jaringan privat diblokir secara default. Loopback, RFC1918, link-local, metadata cloud, dan nama host intranet umum ditolak. Untuk mengakses localhost atau LAN, nyalakan Allow private network access di pengaturan plugin di LM Studio, hanya di percakapan yang membutuhkannya. Model tidak dapat menyalakannya sendiri, dan endpoint metadata cloud tetap diblokir bahkan ketika aktif.
  • Pengalihan diperiksa ulang. Plugin memvalidasi setiap tujuan dan menghapus header mirip kredensial ketika pengalihan lintas origin.
  • Listener peramban tetap pada loopback. Jangan pernah meneruskan atau mem-proxy port 17375. Jabat tangan ekstensi mengidentifikasi klien tetapi bukan autentikasi shared-secret; anggap perangkat lunak lokal sebagai tepercaya.
  • Mode Ask adalah default. Gunakan Act hanya ketika hasil yang diminta memerlukan interaksi peramban yang terlihat, dan jaga peramban sedemikian rupa sehingga Anda dapat menghentikan perilaku tak terduga.
  • Model LM Studio dapat melihat hasil alat. Sebuah run peramban juga mengirim konteks tugas melalui penyedia aktif yang dikonfigurasi di dalam WebBrain. Pilih batas kedua model dengan cermat.

Untuk detail tingkat implementasi (termasuk bagaimana setiap koneksi di-pin ke alamat yang telah diperiksa), baca Catatan keamanan plugin.

Konfigurasi lingkungan jembatan

VariabelDefaultArti
WEBBRAIN_BRIDGE_PORT17375Port loopback yang dihubungi ekstensi.
WEBBRAIN_BRIDGE_PATH/extensionPath WebSocket; harus cocok dengan URL di pengaturan WebBrain.
WEBBRAIN_COMMAND_TIMEOUT_MS30000Anggaran timeout untuk satu perintah dan balasan jembatan.

Jika Anda mengubah port atau path untuk plugin yang dikembangkan secara lokal, perbarui URL jembatan cloud di pengaturan WebBrain agar cocok. Sebagian besar pengguna sebaiknya mempertahankan default.
