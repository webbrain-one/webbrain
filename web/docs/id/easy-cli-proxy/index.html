Jalur kompatibilitas lokal independen

Gunakan akun, bukan kunci API, namun jangan abaikan batas kepercayaan.

EasyCLIProxyAPI dapat mengekspos akun penyedia yang didukung sebagai satu endpoint lokal kompatibel OpenAI. WebBrain dapat menggunakan endpoint itu, tetapi tidak mengembangkan, mengaudit, mendistribusikan, atau mendukung aplikasi proxy tersebut.

Terakhir diverifikasi: 26 Agustus 2026 · EasyCLIProxyAPI v0.2.62

Ini adalah program pihak ketiga yang dapat mengakses kredensial OAuth.

Tidak dikembangkan, dihosting, diaudit, atau dijamin oleh WebBrain

EasyCLIProxyAPI mengelola login penyedia, kredensial lokal, inti CLIProxyAPI yang diinstal terpisah, dan pembaruannya sendiri. Periksa kode sumber dan rilis terkini, unduh hanya dari repositori hulu, dan verifikasi file rilis bila hulu menyediakan ringkasan. WebBrain tidak dapat memeriksa apa yang akan dilakukan build hulu di masa depan.

Menggunakan proxy lokal tidak berarti inferensi juga dilakukan secara lokal. Konteks halaman dan prompt tetap dikirim ke akun penyedia yang dipilih proxy. Aturan penyedia dapat berubah; fakta bahwa sebuah alur OAuth dapat berjalan tidak berarti penyedia mengizinkan semua klien pihak ketiga menggunakannya.

  • OpenAI: langganan ChatGPT dan penagihan API adalah dua produk terpisah. Lihat perbedaan langganan dan API serta Ketentuan Penggunaan terkini.
  • Anthropic: ketentuan konsumennya membatasi akses otomatis atau nonmanusia di luar kunci API atau antarmuka lain yang diizinkan secara eksplisit. Lihat Ketentuan Konsumen terkini.
  • Google: ketentuan Gemini CLI menyatakan bahwa autentikasi OAuth-nya tidak boleh digunakan untuk alat atau layanan pihak ketiga. Lihat ketentuan Gemini CLI terkini.
  • Kimi dan xAI: ketersediaan OAuth di hulu hanyalah kemampuan teknis, bukan izin atau jaminan kompatibilitas. Periksa ketentuan yang berlaku untuk produk, paket, wilayah, dan akun Anda sebelum masuk.

Panduan ini menjelaskan pengaturan kompatibilitas, bukan nasihat hukum. Keputusan atas akun, data, dan kepatuhan tetap menjadi tanggung jawab Anda.

Akun penyediainferensi jarak jauh dan aturan akun

Koneksi pertama tetap di komputer Anda, yang kedua tidak. EasyCLIProxyAPI menyimpan materi OAuth hulu di luar WebBrain; WebBrain hanya menyimpan kunci klien proxy lokal yang Anda masukkan di Pengaturan.

Penyiapan

Hubungkan endpoint lokal

  1. Periksa dan pasang hulu. Unduh EasyCLIProxyAPI dari halaman rilis GitHub. Di Manajemen Versi, pasang inti CLIProxyAPI yang cocok.
  2. Batasi proxy ke alamat loopback. Biarkan alamat penyandang tetap 127.0.0.1, matikan akses LAN, dan jangan pernah meneruskan port 8317. Ganti kunci klien yang pendek atau default dengan nilai acak yang kuat; tergantung versinya, kendali terkait berada di Pengaturan Lanjut atau Akses API.
  3. Otorisasi hanya akun yang benar-benar akan Anda gunakan. Buka OAuth, pilih Codex, Claude, Antigravity, Kimi, atau xAI, lalu selesaikan login di halaman penyedia. Berhenti segera jika penyedia menampilkan ketentuan atau izin yang tidak Anda terima.
  4. Jalankan inti dan salin URL kompatibel OpenAI. Di beranda, jalankan runtime dan salin endpoint OpenAI. Nilai default yang umum adalah http://127.0.0.1:8317/v1; patuhi nilai yang ditampilkan versi yang sedang berjalan.
  5. Buka Pengaturan → Model → LLM di WebBrain. Pilih Lainnya… di menu model di panel samping, lalu cari Proxy lokal kompatibel OpenAI di daftar. Tempelkan URL server dan kunci klien proxy, bukan token OAuth penyedia.
  6. Muat dan pilih model. Klik Muat Model dan pilih model yang diekspos proxy. WebBrain mengisi Jendela konteks secara otomatis dari daftar model proxy, server llama.cpp di belakangnya, atau nama model hosting yang diketahui (maksimal 128k); jika tidak ada yang diketahui, gunakan 64k. Nilai yang Anda ketik tidak ditimpa kecuali server melaporkan jendela yang lebih kecil, jadi turunkan manual jika proxy berada di depan model lokal kecil yang tidak melaporkan jendela. Aktifkan visi hanya jika model itu benar-benar menerima gambar.
  7. Simpan, uji, lalu aktifkan. Jalankan Uji Koneksi dan pastikan hasil keberhasilan berwarna hijau muncul sebelum menjadikannya penyedia chat. Uji mode Ask terlebih dahulu pada konten yang tidak sensitif.
Jangan gunakan 0.0.0.0, IP LAN, terowongan, atau proxy balik publik

Kunci klien lokal bukan sistem autentikasi yang aman untuk akses internet publik. Proses mana pun yang memperoleh kunci dapat mengirim permintaan melalui akun penyedia yang sudah masuk.

Kesalahan kuota atau akunAkun hulu, paket, wilayah, atau kebijakan penyedia menolak permintaan.Berhenti mencoba ulang, periksa akun penyedia secara langsung, dan beralih ke kunci API resmi bila tersedia.
Model atau perilaku tak terduga setelah pembaruanAplikasi desktop, inti, plugin, atau kontrak penyedia berubah.Bandingkan versi, tinjau catatan rilis, lalu jalankan ulang Muat Model dan Uji Koneksi.

Yang dengan sengaja tidak dilakukan WebBrain

  • Tidak mengemas, meluncurkan, memperbarui, atau memverifikasi EasyCLIProxyAPI atau CLIProxyAPI.
  • Tidak menerima atau mengelola refresh token OAuth hulu.
  • Tidak menjanjikan bahwa langganan konsumen menyertakan akses mirip API atau akses otomatis.
  • Tidak melewati kuota penyedia, pembatasan wilayah, peninjauan akun, atau ketentuan.
  • Tidak menjadikan inferensi yang dihosting jarak jauh sebagai inferensi privat atau di perangkat.
