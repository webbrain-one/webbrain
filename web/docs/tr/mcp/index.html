Belgeler / MCP Sunucusu
Gerçek oturum, görev düzeyinde kontrol

Kodlama ajanınızın zaten oturum açtığınız tarayıcıyı kullanmasını sağlayın.

WebBrain MCP, Codex, Claude Code, Cursor, OpenClaw, OpenCode ve diğer stdio MCP istemcilerini gerçek Chromium profilinize bağlar. Tek seferlik kurulum tamamlandıktan sonra, tarayıcı görevini doğal dilde tanımlamanız yeterlidir. Kodlama ajanınız uygun WebBrain aracını seçip çağırır; WebBrain hedefi tarayıcı içinde, kenar çubuğundakiyle aynı modlar, kaynak izinleri ve görünür durdurma kontrolleriyle yürütür.

MCP fonksiyon çağrılarını elle girmenize gerek yok

"Tarayıcımda açık olan panoyu özetlemek için WebBrain kullan" veya "WebBrain'in Act modunu kullanarak bu formu güncelle" deyin. MCP istemciniz bu isteği bir araç çağrısına çevirir ve sonucu aynı sohbette döndürür. Bu rehberin ilerisinde fonksiyon biçiminde gösterilen örnekler esasen hata ayıklama veya istemci geliştiriciler içindir.

Yalnızca Chromium

Köprü, genişletmenin offscreen belgesine gereksinim duyar; bu nedenle Chrome, Edge, Brave, Opera veya Vivaldi kullanın. Firefox genişletmesi bağımsız olarak kullanılabilir olmaya devam eder ancak bu MCP sunucusuna bağlanamaz.

Tam yol

Nerede ne başlatılır

MCP istemciniz npm paketini stdio üzerinden yerel bir alt işlem olarak başlatır. Bu işlem yalnızca 127.0.0.1:17374 adresini dinler. Genişletme ona bağlanır ve her görevi seçilen tarayıcı sekmesinde WebBrain'in ajan döngüsü üzerinden yürütür.

Adım 1 · yalnızca bir kez

Sunucuyu MCP istemcinize kaydedin

Aşağıdaki istemciye özel yapılardan birini yalnızca bir kez kullanın. Bunlar kurulum komutlarıdır; tarayıcı görevi isteme şekliniz değildir. Kayıttan sonra istemci sunucuyu sizin için başlatır ve siz normal şekilde sohbete devam edersiniz; aynı portta elle bir kopyayı eş zamanlı çalıştırmayın.

Codex uygulaması, CLI veya IDE genişletmesi

codex mcp add webbrain -- npx -y @webbrain/mcp-server

Codex, MCP sunucularını ~/.codex/config.toml dosyasında saklar; aynı Codex ana makinesindeki uygulama, CLI ve IDE genişletmesi bu yapılandırmayı paylaşır. Uzun tarayıcı görevleri için dosyayı açın ve araca Codex'in varsayılan tek çağrı bütçesinden daha fazla süre tanıyın:

[mcp_servers.webbrain]
command = "npx"
args = ["-y", "@webbrain/mcp-server"]
tool_timeout_sec = 360

Dosyayı değiştirdikten sonra uygulamayı veya IDE genişletmesini yeniden başlatın. CLI'de girdiyi doğrulamak için codex mcp list çalıştırın ve bağlı sunucuyu denetlemek için bir Codex oturumunda /mcp kullanın. Paylaşılan ana makine yapılandırması ve desteklenen tüm seçenekler için resmî Codex MCP rehberine bakın.

Claude Code

claude mcp add --transport stdio webbrain -- npx -y @webbrain/mcp-server

Açık taşıma türü, güncel Claude Code MCP yapılandırmasıyla eşleşir. Ekledikten sonra sunucunun sağlığını denetlemek için claude mcp list çalıştırın.

Cursor

Cursor'ın MCP ayarlarına yerel bir stdio sunucusu ekleyin veya bu içeriği Cursor'ın kullandığı MCP JSON dosyasına yerleştirin. Biçim, Cursor yerel MCP sunucusu biçimini izler:

{
  "mcpServers": {
    "webbrain": {
      "command": "npx",
      "args": ["-y", "@webbrain/mcp-server"]
    }
  }
}

OpenCode

Bu girdiyi, OpenCode'ın yerel MCP sunucusu biçimini kullanarak ~/.config/opencode/opencode.json dosyasına ekleyin:

{
  "mcp": {
    "webbrain": {
      "type": "local",
      "command": ["npx", "-y", "@webbrain/mcp-server"]
    }
  }
}

OpenClaw

WebBrain'i OpenClaw'da giden bir MCP sunucusu olarak kaydedin. Bu bütünleştirme için openclaw mcp serve komutunu kullanmayın: bu komut OpenClaw'ın kendisini sunucu yapar; yön tam tersidir.

openclaw mcp add webbrain \
  --command npx \
  --arg -y \
  --arg @webbrain/mcp-server \
  --timeout 360

mcp add, stdio sunucusunu kaydetmeden önce yoklar. Kaydedilmiş tanımı denetlemek için openclaw mcp status --verbose çalıştırın. Olağan coding ve messaging araç profilleri yapılandırılmış MCP sunucularını içerir; minimal profili, açık bir bundle-mcp reddi veya sandbox araç ilkesi bunları gizleyebilir. Güncel kayıt ve ilke ayrıntıları için OpenClaw MCP rehberine bakın.

Elle çalıştırma

Elle başlatma, dinleyiciyi tanılamak için yararlıdır ancak MCP'yi normal kullanımda gerekli değildir:

npx -y @webbrain/mcp-server

Bu terminali açık tutun. Kapatmak köprü dinleyicisini de kapatır. Kaynak koddan çalışıyorsanız, mcp-server/ içinde npm install, npm run build ve ardından npm start çalıştırın.

Adım 2

WebBrain'i yerel dinleyiciye yönlendirin

  1. MCP istemcinizi başlatın veya yeniden başlatın. WebBrain sunucusu, genişletme bağlanmadan önce çalışıyor olmalıdır.
  2. WebBrain Ayarlarını açın. Ayarlar → Bridge bölümüne gidin.
  3. URL'yi birebir girin. ws://127.0.0.1:17374/extension adresini yazın.
  4. Eşleştirme anahtarını yapıştırın. Terminalde npx -y @webbrain/mcp-server pairing-key çalıştırın (veya ~/.webbrain/bridge-key dosyasını açın) ve anahtarı Eşleştirme anahtarı alanına yapıştırın. Sunucu yalnızca bu anahtara sahip olduğunu kanıtlayabilen tarayıcıya güvenir. Alan yoksa önce WebBrain'i güncelleyin.
  5. Bulut köprüsünü etkinleştirin. Durum "Bağlanıyor"dan "Bağlandı"ya geçmelidir. Ad tarihsel bir nedenden gelir: bu hedef yereldir.
  6. Uçtan uca bağlantıyı doğrulayın. MCP istemcisinden webbrain_connection çağırmasını isteyin. "Connected" yanıtı; istemcinin, yerel sunucunun, WebSocket dinleyicisinin ve genişletme el sıkışmasının hazır olduğunu kanıtlar.
Aynı anda yalnızca tek bir köprü hedefi

Genişletme tek bir giden köprü soketi tutar: WebBrain Cloud 17373 numarasında, bu MCP sunucusu 17374 numarasında veya LM Studio eklentisi 17375 numarasında. URL'yi değiştirmek hedefi değiştirir; çoğullama yapmaz.

Adım 3 · doğrudan sorun

Tarayıcı görevini doğal dille tanımlayın

Codex, Claude Code, Cursor, OpenClaw veya OpenCode'da isteği bir iş arkadaşına görev verirken yazdığınız gibi yazın. WebBrain'den söz etmek niyetinizi tereddütsüz kılar; sayfayı, beklenen sonucu, kapsamı ve değişikliklere izin verilip verilmediğini dahil edin.

Sayfayı değiştirmeden okuma

WebBrain ile tarayıcımda açık olan Stripe panelini oku. Son yedi günün başarısız ödemelerini müşteri, tutar, para birimi, tarih ve başarısızlık sebebiyle birlikte listele. Hiçbir şeyi değiştirme.

Öngörülebilir JSON döndürme

WebBrain ile tarayıcımda açık olan panodaki tüm gecikmiş faturaları çıkarın. Müşteri, tutar, para birimi, son ödeme tarihi ve fatura URL'si içeren JSON döndürün. Hiçbir şeyi değiştirmeyin.

Sayfayla etkileşim

WebBrain'in Act modunu kullanarak tarayıcımda görünen müşteri kaydını açın ve şirket adını Acme Europe olarak güncelleyin. Herhangi bir nihai gönderim veya onaydan önce durun.

Kodlama ajanı genel okuma veya etkileşim için webbrain_run'i, yapılandırılmış veri istendiğinde webbrain_extract'i seçer. Parametreleri sağlar, çalışmayı izler ve WebBrain'in sonucunu sohbete geri sunar. Ask modu okuyabilir ve veri çıkarabilir; tıklayamaz, yazamaz, gezinemez veya gönderim yapamaz. Act modu etkileşebilir ve WebBrain'in normal tarayıcı taraflı izinlerine tabidir.

Alt katman ayrıntıları — bunları girmenize gerek yok

Yukarıdaki ilk istem için istemci aşağıdakine benzer bir çağrı yapar. Bu gösterim, MCP istemcisi geliştirirken veya hata ayıklarken yararlıdır; sıradan kullanıcılar yok sayabilir.

webbrain_run(
  task: "read the open Stripe dashboard and list failed payments from the last 7 days with customer, amount, currency, date, and failure reason",
  mode: "ask"
)

Etkileşim gerektiren görevler için açıkça "WebBrain'in Act modunu kullan" deyin ve tarayıcıyı görünür tutun. WebBrain, kaynak bazlı normal yetenek onay istemlerini uygulayacaktır.

Altı araç, tek güven sınırı

MCP istemcinizin sizin adınıza kullandığı araçlar

Siz genellikle aracı değil, sonucu seçersiniz. MCP istemciniz bu açıklamaları okur, uygun aracı seçer, girdilerini isteğinize göre doldurur ve sonraki çağrıları yönetir. Bu referans, bu davranışı anlamanız veya hata ayıklamanız içindir.

AraçAmacıÖnemli girdiler
webbrain_runHerhangi bir tarayıcı hedefi; salt okunur veya etkileşimli.task, mode, isteğe bağlı tab_id, wait, timeout_seconds ve yalnızca Act'e açık allow_api_mutations.
webbrain_extractKimliği doğrulanmış sayfa verilerinden öngörülebilir JSON çıkarır. Her zaman Ask modundadır.task, output_schema, isteğe bağlı tab_id, wait ve timeout_seconds.
webbrain_statusArka plandaki bir çalışmayı yoklar veya bilinen tüm çalışmaları listeler.İsteğe bağlı run_id. Listelemek için atlayın.
webbrain_respondKullanıcının yanıtını duraklatılmış bir çalışmaya iletir.run_id, clarify_id, answer, isteğe bağlı timeout_seconds.

Neden MCP tıklama veya yazma aracı yok

WebBrain'in izin denetimleri genişletmenin ajan döngüsündedir. Alt katman primitiflerini doğrudan MCP üzerinden ifşa etmek bu sınırı aşardı. Deterministik alt seviye tarayıcı otomasyonu (Playwright gibi) gerekiyorsa başka MCP sunucularını değerlendirin. WebBrain, işlemleri genişletmenin izin modeli içinde tutarak oturum açmış durumunuzu korur.

Yapılandırılmış JSON isteyin

Normal kullanımda neyin çıkarılacağını söyleyin ve istediğiniz alanları adlandırın: "WebBrain ile açık panodaki tüm gecikmiş faturaları çıkarıp müşteri, tutar, para birimi, son ödeme tarihi ve fatura URL'si içeren JSON döndürün." Yetkin bir MCP istemcisi bu alanları gerekli şemaya çevirip sizin için webbrain_extract çağrısını yapabilir.

Aşağıdaki fonksiyon biçimli örnek, istemci geliştiricileri ve hata ayıklama için eşdeğer araç çağrısını gösterir. Seçim mantığını task içinde anlatın; yalnızca çıktı biçimini output_schema içinde tanımlayın.

webbrain_extract(
  task: "extract every overdue invoice visible in this account; preserve the displayed currency and use ISO dates where the page provides a full date",
  output_schema: {
    type: "object",
    properties: {
      invoices: {
        type: "array",
        items: {
          type: "object",
          properties: {
            customer: { type: "string" },
            amount: { type: "number" },
            currency: { type: "string" },
            due_date: { type: "string" },
            invoice_url: { type: "string" }
          },
          required: ["customer", "amount", "currency", "due_date"]
        }
      }
    },
    required: ["invoices"]
  }
)
  • Açık properties ve required alanları olan bir nesne kökü kullanın.
  • İhtiyacınız olan en dar veri kümesini isteyin. Şema, tarayıcı oturumunun göremediği verilere erişim hakkı vermez.
  • Araç salt okunurdur, ancak sayfa metni ve sonuç yine de WebBrain'in yapılandırdığı LLM sağlayıcısına gönderilir.
  • Sonuç, çalışmanın kalıcı anlık görüntüsü için çok büyükse durum, saklanan sonucun kırpıldığını bildirebilir. İsteği daraltıp yeniden deneyin.

Çalışma yaşam döngüsünü anlayın

Çoğu MCP istemcisi bu yaşam döngüyü sizin için yönetir: sonucu bekler, insan girdisi gerektiğinde WebBrain'in netleştirme sorusunu gösterir ve yanıtınızla devam eder. Aşağıdaki açık çağrılar istemci geliştiriciler, sorun giderme veya istemcinin kasıtlı olarak uzun bir görevi arka planda başlatması için yararlıdır.

Ön plan çağrıları varsayılan olarak bekler. Uzun işler için istemci wait: false ayarlayıp webbrain_status ile yoklayabilir.

runningTarayıcıdaki iş sürüyor
needs_user_inputSoruyu kullanıcıya iletin
completedSonuç hazır
failedHatayı ve kanıtları inceleyin
abortedDurduruldu; önceki işlemler geçerli kalır
# Araç düzeyinde referans
# Beklemeden başlat
webbrain_run(task: "compare the invoices across all visible pages", mode: "ask", wait: false)

# Dönen kimliği yokla
webbrain_status(run_id: "mcp_…")

WebBrain çalışma zaman aşımı, denetimi MCP istemcisine geri verir ancak tarayıcı görevini kasıtlı olarak iptal etmez. Dönen run_id değerini yoklayın. Böylece, görev önemli bir işlem gerçekleştirmiş olabilecekken zaman aşımı onu sessizce sonlandırmaz.

WebBrain soru sorduğunda

Duraklatılmış anlık görüntü, insan tarafından okunabilir bir soru ve clarify_id içerir. Soruyu kullanıcıya gösterin. Yanıtlarını kelimesi kelimesine gönderin; çıkarım yapmayın.

webbrain_respond(
  run_id: "mcp_…",
  clarify_id: "clarify_…",
  answer: "Use the Acme EU account."
)

En küçük yetkiyi seçin

mode: "ask"Okuma, özetleme, karşılaştırma ve veri çıkarma. Sayfa etkileşimi yok.Yalnızca bilgiye ihtiyacınız var. Varsayılan seçenek budur.

MCP istemcisi onayı ile WebBrain onayı birbirinden bağımsız katmanlardır. İstemciniz webbrain_run'ı çağırmadan önce sorabilir; WebBrain de belirli bir kaynak üzerindeki önemli bir işlemden önce sorabilir. Bir onay diğerinin yerini tutmaz.

Korumanız gereken güvenlik sınırları

  • Dinleyiciyi yerelde tutun. 127.0.0.1 adresine bağlanır. 17374 portunu yönlendirmeyin, bir konteyner köprüsüyle yayınlamayın veya bir ağa proxy'lemeyin.
  • Eşleştirme anahtarını iyi saklayın. Yerel loopback tek başına kimlik doğrulama değildir; bu yüzden sunucu, bir sokete ancak o soket eşleştirme anahtarıyla anahtarlanmış bir HMAC kullanarak tek kullanımlık bir sorguyu yanıtladığında güvenir; anahtarın kendisi soketten hiç geçmez. ~/.webbrain/bridge-key dosyasını okuyabilen herkes eşleşebilir, bu yüzden anahtarı sohbete yapıştırmayın. Genişletme sunucunun kimliğini doğrulamaz; yerel kodu ve MCP paketini yine de güvenilir yazılım olarak değerlendirin.
  • Önce Ask kullanın. Salt okunur işler doğrulanması daha kolaydır ve etki alanı daha küçüktür.
  • Act modunda tarayıcıyı görünür tutun. Çalışmayı kenar çubuğundan durdurabilirsiniz; beklenmedik gezinme veya yazma, durdurma gerekçesi sayılmalıdır.
  • Sağlayıcı sınırını aklınızda tutun. MCP köprüsü yerel kalır, ancak sayfa içeriği WebBrain'de yapılandırılan model sağlayıcısına gönderilir. İçeriğin cihazda kalması gerekiyorsa yerel bir model kullanın.
  • Zaman aşımını geri alma sanmayın. İptal, sonraki adımları durdurur; gönderilmiş bir e-postayı, iletilmiş bir formu, satın almayı veya başka tamamlanmış bir işlemi geri alamaz.

Tasarımın tamamı için güvenlik modeline, gizlilik ve veri akışına ve modlar, güvenlik ve gizlilik rehberine bakın.

LM Studio mu kullanıyorsunuz?

LM Studio bu MCP paketini değil, ayrı WebBrain Web Tools eklentisini kullanır. Eklentinin fetch_url ve research_url araçları, tarayıcı genişletmesi gerektirmeden herkese açık sayfaları okuyabilir; tarayıcı araçları ise hedefi 17375 portu üzerinden oturum açmış Chromium oturumunuza devredebilir.

Tek bir köprü hedefi seçin

Yalnızca yayımlanmış eklentiyi kullanmak için @webbrain/mcp-server öğesini LM Studio içinde kaydetmeyin. LM Studio eklenti rehberine bakın ve bu bütünleştirmeye ihtiyaç duyduğunuzda genişletmenin bulut köprüsü URL'sini MCP portu 17374'ten eklenti portu 17375'e çevirin.

Bu sunucunun kasıtlı olarak yapmadıkları

  • Headless bir tarayıcı başlatmaz veya yepyeni bir tarayıcı profili oluşturmaz.
  • Firefox derlemesi üzerinden çalışmaz.
  • Çerezleri, kimlik bilgilerini veya oturum depolamasını dışa aktarmaz.
  • WebBrain'in yaklaşık elli tıklama, yazma, çerçeve, ekran görüntüsü, ağ ve DOM primitifini doğrudan MCP istemcisine açmaz.
  • Köprünün uzaktan sunulmasını güvenli hale getirmez.
  • WebBrain içinde yapılandırılmış bir model gereksinimini ortadan kaldırmaz.

İzole bir profilde deterministik alt seviye tarayıcı otomasyonu gerekiyorsa Playwright tarzı bir MCP sunucu daha uygun olabilir. Belirleyici gereksinim zaten var olan oturum açmış tarayıcı oturumunuz artı WebBrain'in tarayıcı içi güvenlik modeliyse WebBrain MCP kullanın.
