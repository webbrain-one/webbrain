不再猜测设置含义

知道该改什么，也知道什么可以不动。

从侧边栏齿轮或浏览器扩展选项打开设置。所有设置都在同一个页面上：设置导航栏列出每个分区，导航栏顶部的搜索框会搜索全部分区。在侧边栏模型菜单中选择更多…会打开模型 → LLM，在麦克风旁边的 ⚠ 菜单中选择“管理网站权限”会打开权限与隐私。大多数人主要使用“通用”、LLM 分区和“权限与隐私”；其他分区用于解决特定问题。

找到位置

一个页面，一个导航栏

导航栏按以下顺序列出各个分区。缩进的条目归在一个分组名称下。

导航栏包含内容
通用日常偏好和三个组合开关。
模型：LLM、视觉、语音、生成、决策、SafeSocial聊天提供商和可选的辅助模型。
权限与隐私权限提示、网站权限，以及哪些内容可以离开浏览器。
预算花费、等待、步骤和超时的上限。
记忆加密云同步、个人资料自动填充和用户记忆。
技能附加指令与工具。
集成：CAPTCHA、桥接求解服务账户，以及控制这个浏览器的后端。

高级所有细粒度控制项，按标题归类。

搜索

导航栏顶部的搜索框会同时搜索所有分区，并把每个结果显示在所属分区名称下。显示结果时，不会把任何分区标记为当前分区。点击结果上方的分区名称，或在导航栏中选择一个分区，即可打开它；两种方式都会结束搜索。清空搜索也会结束搜索。

窄窗口和旧链接

窗口宽度小于约 880 像素时，导航栏会变成页面上方一条可横向滚动的长条。指向旧的提供商页面和权限页面的链接（无论在书签还是别处）仍然有效：它们会打开设置中对应的分区。

日常使用

通用：大多数人需要的开关

外观、代理活动效果和下载文件夹属于外观或实用设置。接下来是三个组合开关，每个开关一步设置“高级”中的一组相关设置。语言和缩放在侧边栏中选择，这里不再重复。

智能体监督

WebBrain 在代理工作时对它的检查力度。

档位作用使用的设置
严谨每一轮都制定计划，请你批准每个计划，并在检查无法确认某个操作时停下。严格检查开启、精简模式关闭、严格规划、计划审查始终询问
均衡（默认）根据模型自动调整：强大的云端模型自行检查工作，其他模型由 WebBrain 检查。精简模式为自动、尝试规划、低于置信度阈值时审查
快速让模型自行检查工作，并且不为审核计划而停顿。最适合强模型。精简模式开启、尝试规划、从不审查计划
无监督关闭操作检查的“快速”：由模型自行决定是否发送、重试、删除或发布。适合你愿意承担该风险的运行。精简模式开启、尝试规划、从不审查计划、操作检查关闭

“严谨”“均衡”和“快速”保持启用操作检查开启。“无监督”是唯一关闭它的档位，因此由模型自行决定是否发送、重试、删除或发布。任何档位都不改变权限提示，网站权限仍然有效。

图像质量

模型获得的图像细节多少。经济发送更小的截图，每轮最多两张。均衡（默认）发送中等尺寸的截图，在代理打开页面后截一张。清晰发送全尺寸、高细节的截图，并在每次改变页面的操作后截图，图像令牌消耗更多。

完成提醒

当计划等待你审核或任务完成时的提醒方式。全部（默认）会播放提示音、撒彩带并闪烁标签页。安静只闪烁标签页。关闭不做任何提醒。

自定义与微调

每个开关都有一个在“高级”中微调链接，可打开它所代表的那些设置。在那里修改其中任何一项后，开关会显示自定义；选择一个档位即可重置。如果在“高级”中关闭了操作检查，“智能体监督”会显示“自定义”并提示这一点；“严谨”“均衡”和“快速”会重新开启它，而“无监督”则是有意保持关闭的方式。不会保存任何新内容：这些开关读写的就是“高级”中的同一批设置，因此导出的配置和旧的配置文件仍可正常使用。

日常使用

模型 → LLM：选择当前模型

LLM 分区是“模型”下的第一个分区，列出聊天提供商。在侧边栏模型菜单中选择更多…可直接打开它。

一次只有一个提供商处于活动状态。可按本地、云端或路由筛选列表，按提供商、模型或字段搜索，然后打开卡片进行编辑。正确顺序是 保存 → 测试连接 → 设为启用。

本地服务器地址、上下文窗口和提示层级见提供商与模型。

按需使用

模型 → 视觉、语音、生成、决策与 SafeSocial

模型下的其他条目是可选的辅助模型：视觉、语音、生成（图像和视频）、决策和 SafeSocial。配置它们不会改变当前提供商。

视觉和决策模型默认都是自动。在支持硬件 WebGPU 的 Chrome 中，自动模式会在 Compass VLD v6 2B（约 2.4 GB，在本机运行）下载完成后使用它，下载前不使用（如果你之前已下载 Compass VLD Tiny v5 而没有下载 v6，自动模式会使用 Tiny v5）；WebBrain Cloud 激活时，在它下载完成前由 Compass 的托管决策模型回答决策。安装页上的下载本地模型按钮、模型 → LLM 中的 WebGPU 卡片、视觉卡片和末日模式下载的都是同一个模型，一次下载即可同时用于聊天、截图和决策。

视觉

选择由谁读取截图。保存了 OpenAI 兼容端点时，所有截图都交给它，当前提供商继续负责规划和工具调用。没有端点时，当前模型若能看图就自己读取截图；不能看图时，由浏览器内视觉模型读取（仅 Chrome）。全部保持默认即可让当前提供商处理视觉。图像尺寸和每轮上限在高级 → 视觉与截图中，也可以使用“通用”中的图像质量开关；截图打码在权限与隐私中。

浏览器内视觉模型有五个选项：

  • 自动（默认）：Compass VLD 下载完成后使用它（优先用 v6 2B，只下载了 Tiny v5 时用 Tiny v5），只下载了 Ternary Bonsai 2 2B Vision 时使用后者，下载前保持关闭。
  • Compass VLD v6 2B：约 2.4 GB，同一个模型也能聊天和回答决策问题。如果只下载了之前的 Compass VLD Tiny v5（约 2.2 GB），此选项会使用它。
  • Ternary Bonsai 2 2B Vision：约 1.45 GB，同一个模型也能聊天。
  • WebBrain VL 2 450M：约 810 MB，只用于视觉。首次下载会征求你的同意并检查 WebGPU。
  • 关闭：不使用浏览器内视觉模型。

更改选项不会自动下载任何内容，请使用卡片上的下载按钮。任务从不等待下载完成；在浏览器内读取的截图不会离开你的设备。Firefox 没有浏览器内视觉模型。

语音

为录音配置 Whisper 兼容端点。留空时依次尝试已配置的 OpenAI、Groq、LM Studio、llama.cpp。

生成

为图像和视频生成工具连接 fal.ai、OpenRouter、ComfyRouter 或本地 ComfyUI 服务器。默认不配置任何服务。

决策

决策模型是一个小而快的模型，负责回答智能体的是非题和选择题，例如“这个任务完成了吗？”，这样聊天模型就不必处理这些问题。它从不规划、点击或输入。可选三种模式：

  • 自动（默认）：无需设置。在 Chrome 中，Compass VLD 下载完成后（优先用 v6 2B，只下载了 Tiny v5 时用 Tiny v5），用它检查侧边栏任务以及计划监控和计划任务是否真正完成；只下载了 D1 时由 D1 检查。当 WebBrain Cloud（Compass）是你的聊天提供商时，在其中一个下载完成前由 Compass 的决策模型回答。其他情况下不使用决策模型。卡片会显示当前使用的是哪个。
  • 开启：所有决策都使用你配置的提供商：OpenRouter、TypeSafe、本地 System One 服务器、D1，或 Chrome 中的浏览器内聊天模型。所有决策默认开启。展开选择哪些决策使用它可以单独关闭某些决策（验证完成、验证计划监控、验证计划任务完成、快速分类、快速浏览器操作（实验性））并设置阈值。
  • 关闭：从不使用决策模型，包括 Compass 的决策模型。聊天模型仍会检查任务是否完成。

切换模式立即生效；“开启”模式下的提供商字段需要点击保存。测试连接只用固定示例数据发送一次请求。重置会回到自动模式并删除已保存的决策密钥。云端决策提供商会收到有限的任务与页面数据，可能产生费用；“严格的机密处理”会关闭决策模型。在这些模式推出前已开启决策外包的配置会按“开启”继续工作，并保留原有开关。

SafeSocial

可选的本机 Instagram 图片分类器。在你开启前保持关闭；模型只下载一次，并在浏览器内运行。

日常安全

权限与隐私：WebBrain 可以在哪里操作，哪些内容会离开浏览器

保持“执行重要操作前询问”开启。你在侧边栏选择“始终允许”时，WebBrain 会记录一个具体网站的具体能力，并在这个分区中列出。每条永久授权都对应一个明确的“网站 + 能力”组合；允许点击并不自动允许输入、下载、上传、执行 JavaScript 或安排任务。

侧边栏里也有同一个开关：点击输入框中麦克风旁边的 ⚠ 按钮即可打开，里面还有前往这个分区的链接。提示关闭期间，该按钮显示为橙色并带一个圆点。在这里关闭提示不会批准已经在等待的权限卡片，那张卡片仍需你自己回答。

总开关对所有网站生效

关闭它后，在你重新开启之前，所有网站上的操作都不再提示。这比给单个主机授予一项能力宽泛得多。

隐私

设置通常保持何时修改
对截图中的敏感内容进行打码关闭希望在截图发送给视觉模型前，先模糊表单字段和看起来像个人数据的文字。这是尽力而为的保护，不是保证。
严格的机密处理个人日常使用时关闭屏幕共享或导出轨迹，不希望凭据被引用。它还会关闭决策模型。
允许代理访问本地网络关闭必须访问 localhost、内网或私有地址。
限制

预算：单个任务能走多远

“预算”集中了花费、等待和工作量方面的限制：云端费用额度、问题等待你回答的时间、步骤上限和模型请求超时。截图的图像预算位于“高级”中，与其他视觉设置放在一起。

设置默认值限制什么
云端费用会话额度$10.00单个对话中云端和路由模型调用的估算花费。达到额度后，WebBrain 会在下一次调用前停止。
云端费用总额度$10.00所有对话的估算总花费。标签会显示已花费金额，例如 $0.00 / $10.00；重置花费会重新开始计数。
澄清超时60 秒问题卡片等待你回答的时间，超时后 WebBrain 自行作答。滑块两端分别是“立即”和“关闭”。
问题超时时完成任务超时后的答案是继续推进任务，还是选择更安全的做法。
代理最大步骤数130一条消息中的工具调用步骤，不是聊天消息数。
LLM 请求超时120 秒等待模型开始响应的时间。

步骤与超时

步骤上限越高，长流程越有机会完成和恢复，但也可能消耗更多令牌。请求超时只限制模型开始响应前的等待时间，不会中断已经开始流式输出的响应。

无限步骤不等于更可靠

∞ 只会移除机械停止点，不会让模型更不容易循环。除非你正在全程监督长任务，否则保留有限上限。

按需使用

记忆：决定哪些信息长期保留

  • 加密云同步面向 WebBrain Compass 会员；支持的提供商密钥、个人资料和记忆会在上传前用同步密码加密。聊天历史与 OAuth 登录不会同步。
  • 个人资料自动填充以明文保存在当前浏览器配置中，启用后会发送给当前模型提供商。
  • 用户记忆保存稳定偏好；/memory --add 会立即保存。“聊天后自动学习”和“从已完成的表单中学习”是可选项；用户记忆关闭时它们显示为灰色不可用，并且从表单中学习还需要先开启自动学习。
不要把记忆当作密码管理器

不要在个人资料或用户记忆中存放密码、API 密钥、令牌、恢复码等秘密。

信任决定

技能：附加指令与工具

技能可以把指令加入系统提示；含 webbrain-tools 清单的技能还可暴露 HTTP 或下载任务工具。导入的技能文本会复制到浏览器本地存储，并作为系统提示的一部分发送给你配置的 LLM。

“技能”分区先列出已启用的技能，再列出可以启用的内置技能。点击添加技能可打开表单，从网址导入技能或粘贴技能文本；对已启用的技能点击编辑，会在同一表单中载入该技能。

导入即批准

只导入你信任的技能。它声明的 HTTPS 工具可以把声明的输入发送到声明的端点，而不会每次调用都重新询问。下载工具在保存文件前仍会经过常规的下载权限检查。

集成 · 按需使用

CAPTCHA：求解服务账户

“集成”下的 CAPTCHA 分区为 CapSolver、2Captcha、CapMonster Cloud、SolveCaptcha、Anti-Captcha、NopeCHA 和 NoneCap 各提供一张卡片。输入密钥会勾选启用；你也可以取消勾选并保留密钥。保存后生效，测试余额不会自动启用服务。

展开每个服务的高级设置可修改权重，默认依次为 100 至 94。可同时启用多个服务，兼容的服务按权重从高到低尝试。错误或超时后的回退可能产生多次费用。

hCaptcha 使用 NopeCHA 或 NoneCap；其他类型需要相应服务支持和页面参数。请阅读完整 CAPTCHA 指南（英文）。

集成 · 按需使用

桥接：让后端控制这个浏览器

桥接把这个浏览器连接到一个驱动它的程序：Claude Code 或 Cursor 等 MCP 客户端、LM Studio，或 WebBrain Cloud。在你开启允许后端控制此浏览器之前，它保持关闭。预设按钮会为每个后端填入本地 WebSocket 地址；只接受本地 ws:// 地址，MCP 和 LM Studio 还需要各自的配对密钥。在 Chrome 中，实验性 WebMCP 让 WebBrain 发现并运行受支持页面提供的工具。在 Firefox 中，本地 Companion 的受信任自动化卡片也在这里。

设置步骤见 MCP 指南和 LM Studio 指南。

按需使用

离线：末日模式

“离线”分区显示末日模式是否开启以及已安装的内容，例如“已启用 · 2 个已安装 · 1.96 GiB · 手动 更新”。打开末日模式会在新标签页中打开它自己的页面。开关、本地模型和维基百科存档都在那个页面上，因为开启该模式会启动由那个页面管理的下载。

它会下载什么、断网时如何工作，请见末日模式。

专家分区

高级：带着明确目的再打开

“高级”包含所有细粒度控制项，按标题归类。“通用”中的组合开关会替你设置前三组；用搜索框可以直接跳到某个控制项。

视觉与截图视觉模式、视觉模式截图尺寸、自动截图、图像预算

规划控制

  • 尝试规划适合日常使用。WebBrain 会在 Act 或 Dev 工具运行前尝试生成结构化计划；重试后规划仍失败时，WebBrain 会显示警告，这一轮在常规安全措施下不带计划继续。当“自动”为某条消息选择 Act 或 Dev，并确定它是简短、直接的任务（例如打开页面、搜索、填写并提交一个表单）时，尝试规划会跳过完整计划，只做快速的意图检查。包含多个目标、大量条目、多个网站、定时执行，或付款、删除等有风险步骤的任务仍会生成计划；计划审查设为“运行前始终询问”时，每个 Act 或 Dev 轮次也都会生成计划。
  • 严格规划会在无法生成有效计划时取消任务。适用于“没有计划就不行动”比便利更重要的场合。
  • 关闭会省去额外的完整规划调用，但保留快速的意图检查；重试后该检查仍失败时，这一轮同样继续。这样可能更快、更省钱，但会失去计划审查节点。

计划审查暂停决定有效计划何时暂停等待你批准。默认只在规划器的置信度低于低于此置信度时审查（默认 75%）时暂停。

自动截图

自动截图默认为导航时：代理打开页面后截一张图，让视觉模型看到它到达了哪里。状态变化时还会在点击、输入等改变页面的操作后截图，图像令牌消耗更多；每一步在每次工具调用后截图；关闭只在你要求时截图。

何时修改其余设置

设置通常保持何时修改
启用操作检查开启只有在你接受由模型自行决定是否发送、重试、删除或发布时才关闭。网站权限仍然有效。
严格检查关闭希望每项检查都拦下它无法确认的操作，代价是更多运行会卡住。
精简模式自动希望无论使用什么模型，WebBrain 对输入和已完成任务的检查都保持开启（关闭）或关闭（开启）。
记录轨迹关闭比较模型或诊断运行，并接受本地存储。一个开关会连同完整请求细节（提示、消息、工具定义和结果）一起记录每次运行。
站点适配器开启调试令牌使用或禁用站点专用提示。
语音输入开启不需要麦克风按钮。
API 变更观察器开启不希望 WebBrain 观察同一标签页的请求方法来建议 API 快捷方式。
