侧边栏背后的模型

根据耐心、隐私需求与预算选择方案。

WebBrain 内置 114 张提供商卡片，涵盖托管云服务、直接云 API、模型路由和本地 OpenAI 兼容服务器。你只需要一个活动提供商。

快速选择

步骤最少

WebBrain Compass

内置且默认启用，包含每日免费额度，无需模型服务器或 API 密钥。

隐私与离线能力

本地模型

使用 llama.cpp、Ollama、ODS、LM Studio、Jan、vLLM、SGLang 或 LocalAI。

直接使用厂商

云 API

为 OpenAI、Anthropic、Gemini、Mistral、DeepSeek、xAI、Groq 等提供商填写自己的密钥。

模型目录丰富

模型路由

使用一个账户切换许多模型；适合经常试验的用户。

114 张内置提供商卡片

提供商页面新增了 79 个直连 API 与路由器，包括 Azure AI Foundry、Vertex AI、Vertex Anthropic、Cerebras、Cohere、DeepInfra、Perplexity、Vercel AI Gateway、Venice 和多个区域性编程套餐。可以按提供商或模型名称搜索。

大多数卡片使用 API 密钥与 OpenAI 兼容端点。Vertex 卡片使用 Google Cloud 项目、区域和授权密钥；全局区域使用 Google 的全局端点，Vertex Anthropic 还支持 us 与 eu 多区域主机。Cloudflare 接受可选的 AI Gateway ID；对于 @cf/ 模型，留空时自动使用 default 网关。支持流式传输的提供商会在交互式 Ask 中实时显示回复，连接提前结束时自动以非流式方式重试一次。服务返回令牌用量时会直接记录；否则 WebBrain 记录保守估算，避免流式请求绕过成本限额。

有意不提供 GitHub 条目

GitHub 本身不会关闭，但 GitHub Models 将于 2026 年 7 月 30 日退役。GitHub Copilot 需要单独的订阅/OAuth 集成。GitLab Duo 和 SAP AI Core 也需要浏览器扩展不支持的专用认证与部署发现。

配置步骤

  1. 打开提供商页面。在侧边栏模型菜单中选择更多…，或点击设置页顶部的“提供商”链接。LLM 标签页列出聊天提供商。
  2. 找到提供商。使用“本地”“云端”“路由”或搜索框。
  3. 展开卡片并填写值。本地服务器通常需要地址和模型名；云提供商还需要 API 密钥。
  4. 保存。把当前字段写入浏览器。
  5. 测试连接。先修复地址、密钥、模型或服务器错误。
  6. 设为活动。只有测试成功后再切换。保存并不等于已经启用。

字段含义

字段含义建议
服务器 / Base URLOpenAI 兼容根端点或提供商 API 根地址。使用本地应用或提供商给出的精确值，不要粘贴聊天网页地址。
API 密钥发送给提供商用于认证的凭据。本地服务器通常不需要，除非你主动启用了认证。
模型服务器要求的模型标识符。大小写、前缀和拼写必须准确。
上下文窗口一次请求容纳提示、历史、网页内容和工具模式的容量。可靠本地运行建议至少 16k；8k 可配合 Compact；4k 太小。
支持视觉当前模型是否接受图像。只有确认所服务的精确模型支持图像时才开启。
提示层级WebBrain 暴露的提示长度和常规浏览器工具范围。本地模型从 Mid 开始；小上下文用 Compact，能力强的模型用 Full。

服务器常见 Base URLAPI 密钥
llama.cpphttp://localhost:8080通常不需要
Ollamahttp://localhost:11434/v1不需要
ODShttp://localhost:11434/v1可选；使用 ODS .env 中的端口
LM Studiohttp://localhost:1234/v1不需要
Janhttp://localhost:1337/v1可选

连接被拒绝通常是服务器未启动或端口错误；CORS/Origin 错误需要允许浏览器扩展来源。Ollama 常用：OLLAMA_ORIGINS="chrome-extension://*,moz-extension://*" ollama serve。

提示层级

Compact最短提示与最小工具面，适合约 8k 上下文的小型本地模型。
Mid包含常见浏览器任务、iframe、下载、计划任务和表单验证。推荐的本地起点。
Full增加 hover、拖放、框架与 Shadow DOM 等高级回退工具。

云提供商固定使用 Full；本地提供商默认 Mid；Compact 提供商不能使用 Dev 模式。

测试连接失败时

  1. Connection refused：启动本地服务器并确认端口。
  2. CORS/Origin：在服务器中允许 WebBrain 扩展来源。
  3. Unauthorized：确认密钥与 Base URL 属于同一提供商。
  4. Model not found：复制精确模型 ID，或使用 Load models。
  5. 超时：为大型 CPU 本地模型提高“设置 → 预算”中的 LLM 请求超时。
  6. 几轮后失败：确认真实上下文窗口，降低提示层级或扩大模型上下文。

可选的辅助模型

当前提供商负责主要对话、规划和最终回复。提供商页面的其他标签页可独立配置视觉模型、语音（语音转文字）端点、生成媒体、决策模型和 SafeSocial。这些设置不受提供商筛选或切换影响。

视觉和决策模型默认都是自动：在 Chrome 中，Compass VLD v6 2B 下载完成后使用它（只下载了之前的 Compass VLD Tiny v5 时使用 Tiny v5；两者都没有、只下载了 Ternary Bonsai 2 2B Vision 或 D1 时，截图用前者、决策用后者；WebBrain Cloud 激活时决策由 Compass 的托管决策模型处理），下载前不使用。决策模型只回答“这个任务完成了吗？”这类是非题和选择题；选择开启可让 OpenRouter、TypeSafe、本地服务器、D1 或浏览器内模型回答所有决策，选择关闭则从不使用。现有权限与完成检查仍然适用。配置方法和数据共享说明见视觉、语音与决策模型。
