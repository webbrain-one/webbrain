Manliba ng WebBrain

Maraming switch ang browser agent mo, pero hindi mo kailangang matutunan ang lahat bago magsimula.

Magbukas muna ng isang web page at magtanong. Ituturo ng gabay na ito ang pinakmaikling daan patungo sa resulta, at ipapaliwanag ang mas malalim na setting kapag kinakailangan na talaga.

Unang Paggamit

Kumpletuhin ang isang task

Buksan ang side panel, piliin ang tamang mode, at magsimula kahit walang binabago sa settings.

Simulan ang paggamit →Kontrolin ang Agent

Unawain ang mga Setting

Kung ano ang binabago ng bawat seksyon, aling mga default ang angkop sa karamihan, at alin ang maaaring balewalain muna.

Buksan ang gabay sa settings →Pumili ng Model

I-configure ang provider

Gumamit ng WebBrain Compass, cloud API, model routing, o lokal na model.

Pumili ng model →Manatiling May Kontrol

Gumamit nang ligtas ng mode na Act

Matutunan ang mga mode na Ask, Act, at Dev, mga pahintulot ng website, hangganan ng memorya, at mga mapanganib na override.

Tingnan ang gabay sa seguridad →Ilipat ang Nilalaman

Mag-export nang walang alalahanin

Maunawaan ang pagkakaiba ng mga file ng usapan, trace, settings, at naka-save na workflow, at kung alin ang sensitibo.

Alamin ang mga export format →
Unang Pagpapatakbo

Unang 10 minuto

  1. Buksan ang web page na gusto mong trabahuhin. I-click ang icon ng WebBrain para makatabi ang side panel sa page.
  2. Manatili muna sa mode na Ask. Halimbawa: "Ibuod ang page na ito", "Ilista ang mga mahahalagang petsa", "Ihambing ang mga plan sa talahanayan". Maaaring magbasa ang Ask, pero hindi ito nagko-click o nagta-type.
  3. Lumipat sa Act kapag kailangang baguhin ang page. Halimbawa: "I-type ang wireless headphones sa search box at maghanap". Hihingian ka ng pahintulot ang WebBrain bago ang mga mahahalagang aksyon sa bagong site.
  4. Bantayan ang proseso. Maaaring huminto anumang oras gamit ang pindutang Stop o Escape. Agad huminto kapag may hindi inaasahang navigation, pagta-type, o paulit-ulit na aksyon.
  5. Buksan ang Settings kapag may tiyak na kinakailangan. Sapat na ang built-in cloud provider at mga nirerekomendang default na panatilihin ang kaligtasan para sa unang task.
Ang mabuting prompt ay nagsasabi ng resulta

Mas madaling suriin ang "Hanapin ang patakaran sa refund at sabihin kung sakop ang mga item sa sale" kaysa sa "Tingnan mo itong website". Isulat ang layunin at ang hangganan na hindi dapat lumampas ang WebBrain.

Piliin ang mode bago ang prompt

Itanong AskNagbabasa, nagpapaliwanag, naghahambing, nag-e-extract; walang binabago sa page.
Gumawa ActNagko-click, nagta-type, nagna-navigate, nagda-download, nag-iiskedyul ng mga task.
I-develop DevNagdagdag ng mga tool para sa source code, estilo, DOM, frame, at debugging.
Mapa ito, hindi checklist

Mga Setting sa isang sulyap

Hindi mo kailangang i-configure ang lahat. Iisang page na may sidebar ang Mga Setting; bukod sa mga seksyon sa ibaba, naroon din ang 'Mga Kasanayan', 'CAPTCHA', at 'Bridge' para sa mga partikular na add-on, at ang 'Offline' para sa Modo Apocalypse. Ang kulay sa ibaba ng bawat kahon ay nagpapakita kung gaano kadalas ito kailangan ng karaniwang user.
