Docs / Mga Export at Naka-save na Workflow
Madaling ilipat, may mga hangganan

Pumili ng format ng export — o magturo ng workflow — batay sa kailangan mong muling gamitin.

Ang nababasang usapan, diagnostic trace, backup ng mga setting, at muling magagamit na workflow ay ibat-ibang uri ng output. Ang pinakaligtas na pagpili ay mag-export lamang ng pinakakaunting nilalaman na kailangan para sa layunin; kung alam mo na ang mga hakbang, maaaring matutunan ng teach mode ang mga ito mula sa isang manu-manong demonstrasyon.

Anong landas ng export o workflow ang dapat kong gamitin?

LayuninUtosResulta
I-save ang usapang nakikita sa sidebar/exportMadaling basahang Markdown na transcript ng usapan.
I-debug ang naitalang pagpapatakbo ng agent/export --tracesMarkdown na may mga tugon ng modelo, tool call, argumento, at resulta.
I-back up o ilipat ang mga setting/export --configJSON snapshot na webbrain-config/1.
Matutunan ang workflow sa pamamagitan ng isang demonstrasyon/teach --start <pangalan>Naka-save na workflow na walang value na na-compile mula sa iyong manu-manong demonstrasyon.
Ilipat ang isang muling magagamit na awtomasyon/workflow --export <id>Nalinis na JSON definition na webbrain-workflow/1.
Naglalaman ang mga export ng configuration ng plaintext na secret

Maaaring magsama ang snapshot ng mga setting ng API key ng provider, profile data, memorya ng user, custom na kasanayan, at mga piniling pahintulot. Itabi ito nang parang backup ng password; huwag itong i-attach sa pampublikong issue.

Markdown ng Usapan at Trace

Ini-save ng /export ang mga mensaheng kasalukuyang ipinapakita sa sidebar at inirerekord ang bersyon ng WebBrain noong mag-export. Para sa pagbabasa ang file na ito, hindi para i-import pabalik sa WebBrain.

Gumagamit ang /export --traces ng mga lokal na naitalang trace ng kasalukuyang usapan; maaari itong magsama ng prompt, output ng modelo, URL, argumento ng tool, at resulta ng tool. Walang screenshot sa Markdown na ito. Kung naka-off ang tracing noong tumakbo ang isang turn, hindi na mabubuo ang trace ng turn na iyon.

Naghahanda ng ulat ng bug?

Gamitin muna ang export ng usapan. Gamitin ang export ng trace kapag kailangan ang detalye sa antas ng tool; suriin ang personal na data bago magbahagi.

I-back up ang mga Setting

  1. I-type ang /export --config.
  2. Ligtas na itabi ang na-download na webbrain-config-….json.
  3. Ibalik gamit ang /import --file, o i-paste ang JSON pagkatapos ng /import.

Naglalaman ang snapshot ng mga madaling ilipat na halaga ng setting, ngunit hindi nito kasama ang mga usapan, trace, iskedyul na gawain, counter ng paggamit, ipinong gastusin, Cloud Sync session na nakatali sa device, at device ID.

Ginagamit ang field na schema upang tukuyin ang kompatibilidad. Kasalukuyang nag-e-export at tumatanggap ang WebBrain ng webbrain-config/1.

Matuto sa demonstrasyon

Ituro sa WebBrain ang isang workflow sa pamamagitan ng paggawa nito nang isang beses

Gamitin ang teach mode kapag alam mo na ang mga hakbang sa browser at ayaw mong ipagawa muna sa agent ng isang pagpapatakbo na may trace. Ang demonstrasyon ay nakatali sa kasalukuyang tab at sa wakas ay naka-compile sa parehong may-guard na format na webbrain-workflow/1 tulad ng /workflow --save.

  1. Buksan ang simulang pahina. Gumamit ng karaniwang pahinang http(s) at ihinto ang anumang pagpapatakbo ng agent na kasalukuyang hawak ang tab.
  2. Magsimulang magturo. I-type ang /teach --start <pangalan>; lilitaw ang lila na WebBrain Teach indicator sa pahina.
  3. Gawin nang manu-mano ang workflow. Sa parehong tab, magsagawa ng pinagkakatiwalaang click, punan ang field, baguhin ang checkbox o radio button, magsumite gamit ang Enter, at mag-navigate nang eksakto tulad ng muling magagamit na daloy.
  4. Tingnan ang progreso kung kinakailangan. I-type ang /teach upang makita ang pangalan ng aktibong workflow at bilang ng nahawiang aksyon.
  5. I-compile at i-save. I-type ang /teach --end, pagkatapos ay buksan ang /workflow upang patakbuhin, palitan ang pangalan, i-export, o burahin ang natutunang workflow.
Hindi kailanman natututunan ang mga na-type na value

Inirerekord lamang ng page capture code ang semantikong pagkakakilanlan ng field, hindi ang nilalaman nito. Ang bawat napunang field ay nagiging parameter sa runtime; kapag pinatakbuhin ang workflow, muling itatanong ng WebBrain ang kasalukuyang halaga nang lokal.

Mga hangganan ng pag-capture

  • Tanging ang mga pinagkakatiwalaang aksyon sa top-level page ang nahahawian; hindi kasama sa teach record ang mga aksyong ginawa mismo ng WebBrain.
  • Sinusundan ng session ang navigation sa parehong tab at nagrerecord ng hanggang 100 normalisadong aksyon.
  • Hindi maaaring sabay na hawakin ang parehong tab ng teach mode at awtomatikong pagpapatakbo ng agent. Tapusin sa pamamagitan ng /teach --end bago magsimula ng tungkulin ng agent.
  • Nilalaktawan ang hindi suportado o hindi ligtas na target; nagpapakita ang naka-save na resulta ng babala, at sa muling pag-playback ay kailangan pa ring unique at malinaw ang tugma ng semantikong target.
  • Kahit hindi makapag-compile ng workflow, isinasara ng /teach --end ang pansamantalang teach session; ayusin ang pahina o demonstrasyon at magsimula muli.

Gumawa mula sa trace, pagkatapos ay ilipat ang naka-save na workflow

Ang teach mode ang landas ng manu-manong demonstrasyon. Kung natapos na ng agent ang tungkulin nang matagumpay habang nakabukas ang tracing, maaari mong direktang i-save ang pagpapatakbong iyon:

  1. Buksan ang tracing at matagumpay na tapusin ang tungkulin.
  2. I-save gamit ang /workflow --save <pangalan>.
  3. Patakbuhin ang /workflow upang hanapin ang ID.
  4. I-download gamit ang /workflow --export <id>.
  5. Sa ibang WebBrain, gamitin ang /workflow --import --file.

Kailangang suriin o baguhin ang na-export na file ng workflow? Gamitin ang WebBrain Workflow Editor nang lokal sa iyong browser.

Ang portable na workflow ay hindi ang orihinal na trace o teach session. Inaalis ng WebBrain ang mga lumang reference ng elemento, CSS selector, coordinate ng click, query string at fragment ng URL, at ang mga naunang na-type na halaga ng field. Nagiging parameter ang mga na-type na halaga at muling kinokolekta nang lokal sa bawat pagpapatakbo.

Pinapanatili ng file ang mga semantikong paglalarawan ng target at saklaw ng pinagmulan ng site at path, kaya muling mahahanap ng WebBrain ang kasalukuyang elemento at ligtas itong hihinto kapag hindi tiyak ang tugma. Nanatiling may bisa ang mga normal na pahintulot ng execution mode, kumpirmasyon ng pagsusumite, at pag-verify ng resulta.

Nagagawa ang kopya sa pag-import

Nagtatalaga ang WebBrain ng bagong lokal na ID at timestamp sa halip na itabi ang nasa workflow. Ang mga portable na file ng workflow ay hanggang 1 MiB.

Suriin bago magbahagi

FileSuriin kahit hindi hihinda
Markdown ng UsapanMga mensahe at system notice.
Markdown ng Trace o JSON ng Trace pagePrompt, URL, argumento, resulta, at kahit anong naka-embed na screenshot.
JSON ng mga SettingHuwag ibahagi maliban kung sinadyang inalis ang lahat ng secret at pribadong halaga.
JSON ng WorkflowPangalan, metadata ng pinagmulan, pinagmulan ng site at saklaw ng path, label ng target, at intensyon ng hakbang.

Para sa kumpletong format sa antas ng field at mga patakaran ng kompatibilidad, tingnan ang teknikal na reference ng format (Ingles).
