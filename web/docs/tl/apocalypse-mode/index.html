WebBrain, handa kahit walang internet

Maghanda ng lokal na intelihensiya at praktikal na kaalaman bago mo ito kailanganin.

Bumubuo ang Apocalypse Mode ng isang offline-ready na kagamitan sa loob ng iyong browser: mga text at vision model sa device sa mga suportadong Chromium system, isang naroronong archive ng Wikipedia, at isang Emergency Box ng mga libro at field reference.

Text model2.4 GB · lokal na WebGPU inference
Vision modelopsyonal · nanatiling lokal ang mga screenshot
WikipediaSimple English · maaaring hanapin offline

Ano ang ibig sabihin ng "offline"

Kailangan mo ng koneksyon sa internet para sa unang download. Kapag naitabi na ang mga file ng model, ang archive ng Wikipedia, at mga napiling dokumento, ang mga pangunahing daloy ng inference, paghahanap, at pagbabasa ay tumatakbo nang lokal mula sa browser profile. Ginagawa ng WebGPU ang model inference sa device; ang mga na-download na screenshot ay hindi nangangailangan ng remote na vision service.

Maghanda sa isang karaniwang araw

Mas madali ang malalaking download at pagsusuri ng storage kapag nahuhulaan ang kuryente, koneksiyon, at oras. Paganahin ang mode, hayaang maabot ng bawat kinakailangang item ang status na Ready, at subukan ang mga reader bago ituring na handa ang kagamitan.

Hindi ginagawa ng Apocalypse Mode na gumagana offline ang lahat ng website o task ng WebBrain. Ang mga live page, hosted na model provider, kasalukuyang balita, at anumang resource na hindi mo na-download ay nangangailangan pa rin ng network. Naghahanda ito ng isang self-contained na lokal na core; hindi ito kopya ng internet.

Kung hindi lumilitaw ang mga card ng text at vision, unang kumpirmahin na ginagamit mo ang Chromium build sa hardware at browser version na may WebGPU support.

Bumuo ng basic na kagamitan

  1. Buksan ang Apocalypse Mode. Sa Mga Setting, piliin ang Offline sa sidebar at piliin ang Buksan ang Modo Apocalypse.
  2. Suriin ang iyong storage at koneksyon. Kasama sa Chromium basics ang isang 2.4 GB na text model na nagbabasa rin ng mga larawan at ang kasalukuyang archive ng Simple English Wikipedia. Ang hiwalay na vision model sa browser ay opsyonal: mga 1.45 GB para sa Ternary Bonsai 2 2B Vision o mga 810 MB para sa WebBrain VL 2 450M. Mag-iwan ng karagdagang espasyo para sa pansamantalang estado ng download at mga resource ng Emergency Box.
  3. I-on ang mode. Sa mga suportadong Chromium system, awtomatikong sini-simula ng WebBrain ang text model at ang kinakailangang archive ng Wikipedia. Hindi nito kailanman mag-ii-download ng vision model nang kusot.
  4. Panatilihing bukas ang browser para sa mga download ng model. Maaari kang lumipat ng tab o isara ang Settings, ngunit dapat nakabukas ang Chrome habang patuloy ang lokal na transfer ng model. Subaybayan ang progress ng bawat item sa halip na umasa lamang sa kabuuang bilang ng storage.
  5. Ayusin ang anumang hindi ready. Ipagpatuloy ang naka-pause na item, ulitin ang error, o magpalaya ng storage. Ang pag-aalis ng kumpletong model ay nagbubura ng mga cached file nito at nangangailangan ng muling download bago magamit offline.
  6. Subukan ang kagamitan. Gamitin ang vision test, buksan ang reader ng Wikipedia, maghanap ng artikulo, at buksan ang kahit isang naka-install na PDF. Hindi plano ang download hangga't hindi mo napatunayang mababasa mo ito.

Ano ang ginagawa ng mga lokal na model

Text · 2.4 GB

Compass VLD v6 2B

Idedownload ng WebBrain ang webbrain-one/webbrain-compass-vld-v6-2b-onnx, ang fine-tune nito sa LFM3-VLD-2B (ang LFM3-VLD-2B ay adaptation ng WebBrain sa LFM3-VL-2B ng Liquid), para sa lokal na chat na may tool call sa pamamagitan ng WebGPU. Ang parehong model ay nagbabasa rin ng mga screenshot at sumasagot sa mga decision question ng WebBrain. Inaalok din ng listahan ng Text Model ang naunang default, Compass VLD Tiny v5 (mga 2.2 GB). Gamitin ang nuclear control sa standalone chat kapag ready na ito.

Vision · opsyonal

Ternary Bonsai 2 2B Vision o WebBrain VL 2 450M

Binibigyang-kahulugan ng lokal na vision layer ang mga screenshot sa device, ginagawa ang visual evidence na konteksto nang hindi ipinapadala ang larawan sa remote na vision provider. Ang card ng Vision Model ay nagbabahagi ng isang pagpipilian sa Mga Setting → Mga modelo → Bisyon: ang Auto (default) ay gumagamit ng Compass VLD kapag na-download na ito (v6 2B, o Tiny v5 kung ito lang ang na-download), at Ternary Bonsai 2 2B Vision (mga 1.45 GB) kung ito lang; maaari mo ring piliin ang WebBrain VL 2 450M (mga 810 MB, vision lang, kailangan muna ng pahintulot sa Mga Setting → Mga modelo → Bisyon) o Off. Kung ang iyong Text Model ay Compass VLD v6 2B, Compass VLD Tiny v5 o Ternary Bonsai 2 2B Vision, nagbabasa na ito ng mga larawan at walang kinakailangang karagdagang download.

Hindi pumapalit ang Apocalypse Mode sa napili mong provider

Ang na-download na text model ay isang run-scoped na pagpipilian para sa standalone chat. Ang pagpapagana o pag-download nito ay hindi tahimik na binabago ang provider na ginagamit ng mga karaniwang usapan ng WebBrain.

Panatilihin ang Wikipedia na talagang maaari mong hanapin

Idedownload ng basic setup ang pinakabagong compact, text-only na archive ng Simple English. Buksan ang Manage archives kapag gusto mo ng ibang wika, mas kumpletong edisyon, o edisyong may mga larawan. Tinutukoy ng WebBrain ang kasalukuyang bersyon, petsa, at eksaktong laki ng archive bago i-install.

Maaaring kumuha ang lokal na standalone chat ng mga compact, may pinagmulang talata mula sa naka-install na archive. Kapag pinalitan mo ang kinakailangang archive ng Simple English, pinapanatili ng WebBrain ang lumang kopya hanggang sa matagumpay na ma-download at ma-verify ang kapalit.

Sunuran nang mabuti ang Emergency Box

Ang Emergency Box ay isang curadoryang lokal na shelf, hindi awtomatikong pag-aangkin na mahalaga ang bawat dokumento. Pinagsasama nito ang built-in na communication lexicon, mga offline na edisyon ng Wikipedia, mga textbook ng OpenStax, mga reference sa emergency health, at mga field manual. Hanapin o i-filter ang catalog, saka i-download lamang ang angkop sa iyong mga maaaring pangangailangan at available na storage.

Kasama sa WebBrain ang emergency communication

Ginagamit ng Universal Basic Lexicon ang CC0 PanLex Swadesh Corpus at available ito nang hindi na kailangan ng ibang download. Isinisalin nito ang 110 pang-araw-araw na konsepto sa 1,756 ISO na wika at 2,064 uri ng wika. Pumili ng target na wika, maghanap sa English o sa target na script, at buksan ang isang salita bilang malaking card na maaaring ipakita sa kapwa tao.

Ito ay tulong sa antas ng salita, hindi awtomatikong pagsasalin. Ang snapshot ng source ay mula noong Enero 2017, nag-iiba ang saklaw, at maaaring malabo, diyalekto-tukoy, hindi kumpleto, o luma ang isang termino. Ipinapakita ng reader ang mga kulang na termino sa halip na gawin-gawin ito. Gumamit ng sanay na interpreter kapag kritikal ang katumpakan. Para sa mas malawak na diksyunaryo, nagli-link ang reader sa Kiwix Wiktionary — ang buong English na text-only archive noong Mayo 2026 ay mga 8.5 GB — at sa mga download ng language pair ng FreeDict, na nag-iiba ang laki at lisensya.

  • Ipinapakita ng parehong button ang live na tantaya para sa kanilang natitirang download. Sinusundan ng Download all ang kasalukuyang search o category view, at nilalaktawan ang mga naka-install nang resource.
  • Saklaw ng built-in OpenStax snapshot ang 118 English at 11 Spanish na textbook; ipinapakita ng bawat resource card ang wika.
  • Maaaring i-download, i-pause, ipagpatuloy, basahin, at alisin ang indibidwal na PDF.
  • Pinoproseso ng batch download ang isang resource bawat oras, kaya hindi nagkokompetensya ang malalaking transfer.
  • Isinusulat ang mga PDF sa browser-managed na storage. Panatilihing bukas ang window ng Emergency Box habang nagtatransfer ng PDF; maaaring ipagpatuloy ang naka-pause na progress.
  • Suriin ang mga petsa ng paglalathala. Nagiging luma ang gabay sa medikal, at gamitin ang propesyonal na pangangalaga kapag available.
Mga tantaya lamang ang mga numerong ito ng storage

Ang mga tantaya ng PDF ay batay sa mga file ng publisher na available noong Agosto 17, 2026. Maaaring palitan ng publisher ang mga file, maaaring magbago ang catalog ng OpenStax, at hindi kasama sa mga numero ang overhead ng storage ng browser. Ang bilang na 0.004 GB para sa lexicon ay pinagbilog mula sa built-in na 3.4 MiB na data file. Muli itong binanggit sa footer ng Emergency Box.

Hindi katumbas ng emergency training ang library

Sanayin ang pagbubukas ng mga materyales, magkaroon ng mga karaniwang emergency supply, at sundin ang gabay ng mga lokal na awtoridad at kwalipikadong propesyonal. Ang Apocalypse Mode ay isang tool ng impormasyon; hindi nito mapapalitan ang kahusayan sa medikal, pagsasalin, kaligtasan, o ebakwasyon.

Alamin kung saan nakatago ang kagamitan

Nasa storage na pinapamahalaan ng browser profile ang mga na-download na archive at PDF; nasa lokal na cache ng browser ang mga weight ng model. Maaaring burahin ang kagamitan ang paglilinis ng storage ng site o extension, pagtanggal ng browser profile, pag-uninstall na may pag-aalis ng data, o paggamit ng cleanup utility. Ang sinasadyang pag-aalis ng mga resource sa loob ng Apocalypse Mode ay nagpapalaya ng storage na iyon.

  • Pinapause ng pag-disable ng Apocalypse Mode ang mga hindi pa tapos na trabaho ngunit pinapanatili ang mga naka-install na archive.
  • Iiwasan ng pag-hinto o pag-aalis ng kinakailangang basic Wikipedia download ang agarang tahimik na muling download; simulan ito nang malinaw kapag handa ka na.
  • Panatilihing available ang iyong browser profile at paulit-ulit na buksan ang kagamitan upang matiyak na nababasa pa ang data.
  • Para sa resilience lampo sa isang device, kung praktikal, magtabi ng mga independiyenteng lisensyado na source file o Kiwix archive sa storage na ikaw ang namamahala.

Isang readiness check na dapat ulitin

  1. Ipinapakita ng bawat kinakailangang item ang Ready.
  2. Sumasagot ang standalone lokal na text chat nang walang network.
  3. Kumpleto ang vision test sa device.
  4. Binubuksan ng Wikipedia search ang buong lokal na artikulo.
  5. Nabubuksan sa reader ang kahit isang na-download na PDF.
  6. May sapat pang libreng storage ang browser profile.
  7. Alam mo kung aling mga kakayahan pa rin ang depende sa live website o hosted provider.

Ulitin ang check na ito pagkatapos ng browser migration, paglilinis ng storage, malalaking update, o matagal na panahon nang hindi ginagamit.
