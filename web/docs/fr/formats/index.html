Docs / Exports et workflows enregistrés
Portables, avec des limites

Choisissez un export — ou enseignez un workflow — selon ce que vous devez réutiliser.

Une conversation lisible, une trace de diagnostic, une sauvegarde des réglages et un workflow réutilisable sont des artefacts différents. Le choix le plus sûr est le plus étroit qui corresponde à votre objectif ; si vous connaissez déjà les étapes, le mode Enseignant peut les apprendre à partir d'une seule démonstration manuelle.

Quel export ou quel workflow dois-je utiliser ?

Les exports de configuration contiennent des secrets en clair

Un instantané des réglages peut contenir des clés API de fournisseurs, des données de profil, la mémoire utilisateur, des compétences personnalisées et des choix d'autorisation. Conservez-le comme une sauvegarde de mots de passe ; ne le joignez jamais à un issue public.

Markdown des conversations et des traces

/export enregistre les messages actuellement affichés dans le panneau latéral et consigne la version de WebBrain utilisée pour l'export. Ce fichier est destiné à la lecture et ne peut pas être réimporté dans WebBrain.

/export --traces utilise les traces enregistrées localement pour la conversation actuelle. Il peut contenir des prompts, des sorties du modèle, des URL, des arguments d'outils et des résultats d'outils. Les captures d'écran sont omises de ce fichier Markdown. Si le traçage était désactivé pendant un tour, sa trace ne peut pas être reconstituée par la suite.

Sur le point de déposer un rapport de bug ?

Commencez par l'export de conversation. N'utilisez l'export de traces que si des détails au niveau des outils sont nécessaires, et vérifiez chaque fichier à la recherche de données personnelles avant de le partager.

Sauvegarder les réglages

  1. Saisissez /export --config.
  2. Conservez en lieu sûr le fichier webbrain-config-….json téléchargé.
  3. Restaurez-le avec /import --file, ou collez son JSON après /import.

L'instantané contient des valeurs de réglages portables, mais pas les conversations, les traces, les tâches planifiées, les compteurs d'utilisation, les dépenses cumulées, ni les sessions Cloud Sync liées à un appareil et les identifiants d'appareil.

Le champ schema identifie la compatibilité. WebBrain exporte et accepte actuellement webbrain-config/1.

Apprendre par la démonstration

Apprenez un workflow à WebBrain en le réalisant une fois

Utilisez le mode Enseignant lorsque vous connaissez les étapes dans le navigateur et souhaitez les enregistrer sans demander d'abord à l'agent d'effectuer une exécution tracée. La démonstration est limitée à l'onglet et se compile dans le même format webbrain-workflow/1 sécurisé que /workflow --save.

  1. Ouvrez la page de départ. Utilisez une page http(s) classique et arrêtez toute exécution d'agent qui occupe actuellement cet onglet.
  2. Commencez l'enseignement. Saisissez /teach --start <nom> ; un indicateur WebBrain Teach violet apparaît sur la page.
  3. Exécutez le workflow manuellement. Dans cet onglet, effectuez les clics de confiance, remplissez les champs, cochez ou décochez cases et boutons radio, validez avec Entrée et naviguez exactement comme le flux réutilisable l'exige.
  4. Vérifiez la progression au besoin. Saisissez /teach pour voir le nom du workflow actif et le nombre d'actions capturées.
  5. Compilez et enregistrez. Saisissez /teach --end, puis ouvrez /workflow pour exécuter, renommer, exporter ou supprimer le workflow appris.
Les valeurs saisies ne sont jamais apprises

Le code de capture de la page enregistre l'identité sémantique d'un champ, jamais son contenu. Chaque champ rempli devient un paramètre d'exécution ; lors d'une exécution ultérieure du workflow, WebBrain redemande la valeur courante en local.

Limites de la capture

  • Seules les actions de confiance dans la page de premier niveau sont capturées ; les actions effectuées par WebBrain lui-même sont exclues de l'enregistrement.
  • La session suit la navigation dans le même onglet et enregistre au plus 100 actions normalisées.
  • Le mode Enseignant et les exécutions automatisées d'agents ne peuvent pas occuper le même onglet simultanément. Terminez avec /teach --end avant de lancer une tâche d'agent.
  • Les cibles non prises en charge ou non sûres sont ignorées ; un avertissement s'affiche dans le résultat enregistré, et la relecture exige toujours une correspondance sémantique unique et non ambiguë.
  • Même si aucun workflow ne peut être compilé, /teach --end clôt la session d'enseignement temporaire ; corrigez la page ou la démonstration et recommencez.

Depuis une trace créer, puis déplacer un workflow enregistré

Le mode Enseignant convient aux démonstrations manuelles. Si l'agent a déjà réussi la tâche avec le traçage activé, enregistrez plutôt cette exécution :

  1. Activez le traçage et terminez la tâche avec succès.
  2. Enregistrez-la avec /workflow --save <nom>.
  3. Exécutez /workflow pour trouver son ID.
  4. Téléchargez-la avec /workflow --export <id>.
  5. Utilisez /workflow --import --file dans une autre instance de WebBrain.

Vous devez inspecter ou modifier un fichier de workflow exporté ? Utilisez l'Éditeur de workflows WebBrain directement dans votre navigateur.

Un workflow portable n'est pas la trace ou la session d'enseignement d'origine. WebBrain supprime les anciennes références d'éléments, les sélecteurs CSS, les coordonnées de clic, les chaînes de requête et fragments d'URL, ainsi que les valeurs saisies dans les champs. Les valeurs deviennent des paramètres, collectés à nouveau en local à chaque exécution.

Le fichier conserve les descriptions sémantiques des cibles, l'origine du site et la portée des chemins, afin que WebBrain puisse retrouver l'élément actuel et s'arrêter de façon sûre en cas de correspondance ambiguë. Les autorisations normales du mode Exécution, la confirmation des envois et la vérification des résultats restent en vigueur.

L'importation crée une copie

WebBrain attribue un nouvel ID local et de nouveaux horodatages, sans écraser un workflow existant. Les fichiers de workflow portables sont limités à 1 MiB.

Vérifier avant de partager

FichierVérification minimale
