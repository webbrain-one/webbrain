# Embedded AI product examples

These authentic product-demo screenshots illustrate the Gmail and X examples
on `/websites/`. They contain public demonstration content, not private account
data. The surrounding frame, spacing, and shadows are CSS; the interfaces have
not been recreated or generated with AI.

- File: `gmail-gemini.png` (1920 × 1080).
- Source: Google Workspace's [official demonstration](https://www.youtube.com/watch?v=jJkLX8N4axI&t=60s),

- Captured November 14, 2026, from the original video frame at 60 seconds.
- Shows the appointment-confirmation search results and Gemini's confirmation

- The page uses CSS to hide only the video's unused right margin. The full-image
  link preserves the complete, unedited source frame.
- Capability reference: [Collaborate with Gemini in Gmail](https://support.google.com/mail/answer/14355636?hl=en).
