契約済みのAIプランをWebBrainで活用

WebBrain Companion はメニュー バーまたはシステム トレイにあります。 Claude、ChatGPT、Google、Grok、または Kimi に一度サインインすると、WebBrain はコンピューター上の 1 つのアドレスでそれらすべてに到達します。トレイには、各プランがどれだけ残っているか、いつリセットされるかが表示されます。

それ以外はすべて 1 つの小さなパネルで行われます

アイコンをクリックして開きます。 1 ページには、WebBrain のアドレス、残りのすべてのプラン、および 2 つのローカル モデルが保持されます。行をクリックして詳細を表示するか、歯車をクリックして設定を表示します。それはあなたの明るいまたは暗い設定に従い、英語とトルコ語を話します。

Bonsai 2 27B、マシンに合わせたサイズ

PrismML の Ternary Bonsai 2 27B は、270 億のパラメータを 5.95 GB に詰め込みます。コンパニオンは、Q8_0 ビジョン プロジェクターと PrismML の llama.cpp ビルドとともに、または Apple Silicon 上の MLX パックとしてインストールし、サブスクリプションの横に bonsai-2-27b としてリストします。

何かをダウンロードする前に、モデルがどこで実行されるか、画像入力が適合するかどうかが判断されます。ビジョン プロジェクターは、モデルとそのコンテキストの後に約 1 GB の GPU メモリが残っている場合は GPU で動作し、システム RAM のみに余裕がある場合は CPU で動作し、それ以外の場合はオフのままです。パネル内の選択を上書きできます。

コンパニオンのプランナーが総メモリと空きメモリから計算します。インストール時のマシン上の数値によって決まります。 Apple Silicon では、MLX パックに独自のビジョンタワーが搭載されているため、画像は常にオンになります。

WebBrain の意思決定モデル、ブラウザ外

WebBrain の d1 モデルは、タスクが完了したかどうかなど、ページと最大 4 つのスクリーンショットに関するはい/いいえ、選択、スコアの質問に答えます。コンパニオンは ONNX Runtime で実行され、HTTP 経由で応答するため、ブラウザー タブに 1.9 GB を読み込む必要はありません。その Go ポートは、WebBrain の JavaScript アダプターと同じトークンと確率を返します。ネイティブ d1 は、Windows、Linux、および Apple Silicon Mac で利用できます。 Intel Mac では利用できません。

WebBrainを接続する

これを一度実行します。このコンピューター上のアプリには API キーは必要ありません。

  1. コンパニオンをインストールして開きます。パネルにサブスクリプションを追加し、ブラウザーでサインインを完了します。
  2. デフォルトのアドレスは http://127.0.0.1:8327/v1 です。ポートが変更された場合は、パネルまたはトレイ メニューに表示されているアドレスをコピーします。
  3. でWebBrainを開きます。プロバイダーページ (もっと…サイドパネルのモデルメニューで)、選択しますWebBrain Companion。アプリに別のポートが表示されない限り、デフォルトのアドレスをそのままにしておきます。このコンピューターでは API キーは必要ありません。
  4. Load Models をクリックし、モデル Save を選択し、カードをアクティブ化する前に Test Connection を実行します。画像を受け入れるモデルに対してのみビジョンをオンにします。

このコンピューター上のすべての OpenAI、Anthropic、または Gemini クライアントは同じアドレスを使用できます。別のデバイスから使用するには、パネルの設定でネットワーク アクセスをオンにします。そのデバイスには、パネルに表示されている API キーが必要です。

サインインする前に

コンピューターに残るもの

  • このコンピュータでは API キーは必要ありません。コンパニオンは 127.0.0.1 からのリクエストにのみ応答し、Web ページを拒否するため、アクセスしたサイトでプランを費やすことができません。 WebBrain などのブラウザ拡張機能とこのコンピューター上のアプリで使用できます。
  • 他のデバイスは、パネルの設定でネットワーク アクセスをオンにしている場合にのみ接続できます。次に、0.0.0.0 をリッスンし、パネルに表示されている API キーが必要になります。
  • ログインはユーザー フォルダーに保存され、所属するプロバイダーにのみ送信されます。
  • 分析はありません。サインインするプロバイダーとは別に、CLIProxyAPI のパブリック モデル リストのみをフェッチし、モデルをインストールする場合は、Hugging Face、GitHub、および MLX、PyPI からそのファイルをフェッチします。
  • サブスクリプションに送信されたプロンプトは引き続きそのプロバイダーに送信されます。マシン上では Bonsai 2 27B と d1 のみが実行されます。

プロバイダーが決定すること

  • プロキシ経由で機能するサブスクリプションは、プロバイダーが許可するサブスクリプションと同じではありません。 Anthropic の消費者規約では、API キー以外の自動アクセスが制限されており、Google の Gemini CLI 規約では、そのサインインをサードパーティ ツールで使用できないと規定されています。
  • プランを追加する前に、プランと地域の条件を確認してください。アカウントが重要な場合は、プロバイダー API キーを使用する方が安全です。
  • 公衆 Wi-Fi ではネットワーク アクセスをオフにし、ポート 8327 をインターネットに転送しないでください。 API キーはインターネット グレードのセキュリティではありません。

WebBrainをコンパニオンに接続

WebBrain Companion は、GPL-3.0-or-later ライセンスに基づくフリー ソフトウェアであり、CLIProxyAPI が組み込まれています。 Anthropic、OpenAI、Google、xAI、Moonshot AI、メタ、Cognitionとは無関係です。
