Ang mga AI subscription mo, handa nang gamitin sa WebBrain

Ang WebBrain Companion ay nakatira sa iyong menu bar o system tray. Mag-sign in sa Claude, ChatGPT, Google, Grok o Kimi nang isang beses, at mararating ng WebBrain ang lahat ng ito sa isang address sa iyong computer. Ipinapakita ng tray kung gaano karami sa bawat plano ang natitira at kung kailan ito nagre-reset.

Bonsai 2 27B, sukat sa iyong makina

Ang Ternary Bonsai 2 27B ng PrismML ay naglalaman ng 27 bilyong parameter sa 5.95 GB. Ini-install ito ng kasama kasama ang Q8_0 vision projector nito at ang build ng PrismML ng llama.cpp, o bilang MLX pack sa Apple Silicon, at inililista ito sa tabi ng iyong mga subscription bilang bonsai-2-27b.

Bago mag-download ang anumang bagay, gagana ito kung saan tumatakbo ang modelo at kung umaangkop ang input ng imahe. Ang vision projector ay napupunta sa GPU kapag humigit-kumulang 1 GB ng GPU na memorya ang natitira pagkatapos ng modelo at ang konteksto nito, sa CPU kapag ang system na RAM lang ang may puwang, at nananatili kung hindi. Maaari mong i-override ang pagpipilian sa panel.

Ang modelo ng desisyon ng WebBrain, sa labas ng browser

Sinasagot ng modelong d1 ng WebBrain ang oo/hindi, mga tanong sa pagpili at marka tungkol sa isang page at hanggang sa apat na screenshot, gaya ng kung tapos na ang isang gawain. Pinapatakbo ito ng kasama sa ONNX Runtime at sumasagot sa HTTP, kaya hindi kailangang mag-load ng 1.9 GB ang tab ng browser. Ang Go port nito ay nagbabalik ng parehong mga token at probabilities bilang JavaScript adapter ng WebBrain. Ang katutubong d1 ay available sa Windows, Linux at Apple Silicon Mac; ito ay hindi magagamit sa Intel Mac.

Ikonekta ang WebBrain

Gawin mo ito minsan. Ang mga app sa computer na ito ay hindi nangangailangan ng API key.

  1. I-install ang kasama at buksan ito. Magdagdag ng subscription sa panel nito at tapusin ang pag-sign in sa iyong browser.
  2. Ang default na address ay http://127.0.0.1:8327/v1. Kung nagbago ang port, kopyahin ang address na ipinapakita sa panel o tray menu.
  3. SaWebBrain, buksan angMga tagapagbigaypahina (Higit pa…sa menu ng modelo ng side panel) at piliinWebBrain Companion. Panatilihin ang default na address nito maliban kung nagpapakita ang app ng isa pang port. Walang API key ang kailangan sa computer na ito.
  4. I-click ang Mag-load ng Mga Modelo, pumili ng modelo, Save, at patakbuhin ang Test Connection bago i-activate ang card. I-on lang ang vision para sa isang modelong tumatanggap ng mga larawan.

Anumang OpenAI, Anthropic o Gemini client sa computer na ito ay maaaring gumamit ng parehong address. Upang gamitin ito mula sa isa pang device, i-on ang access sa network sa mga setting ng panel; kailangan ng device na iyon ang API key na ipinapakita ng panel.

Bago ka mag-sign in

Ano ang nananatili sa iyong computer

  • Sa computer na ito walang API key ang kailangan: ang kasama ay sumasagot lamang ng mga kahilingan mula sa 127.0.0.1 at tinatalikuran ang mga web page, kaya ang isang site na binibisita mo ay hindi maaaring gastusin ang iyong mga plano. Magagamit ito ng mga extension ng browser gaya ng WebBrain at mga app sa computer na ito.
  • Makakakonekta lang ang ibang mga device kung i-on mo ang access sa network sa mga setting ng panel. Pagkatapos ay nakikinig ito sa 0.0.0.0, at kailangan nila ang API key na ipinapakita ng panel.
  • Ang mga pag-login ay nakaimbak sa iyong folder ng user at ipinadala lamang sa provider na kinabibilangan nila.
  • Walang analytics. Bukod sa mga provider kung saan ka nagsa-sign in, kinukuha lang nito ang listahan ng pampublikong modelo ng CLIProxyAPI, at, kapag nag-install ka ng modelo, ang mga file nito mula sa Hugging Face, GitHub at, para sa MLX, PyPI.
  • Ang mga prompt na ipinadala sa isang subscription ay mapupunta pa rin sa provider na iyon. Tanging Bonsai 2 27B at d1 lang ang tumatakbo sa iyong makina.

Kung ano ang desisyon ng iyong provider

  • Ang isang subscription na gumagana sa pamamagitan ng isang proxy ay hindi katulad ng isa na pinapayagan ng provider. Ang mga tuntunin ng consumer ng Anthropic ay naghihigpit sa awtomatikong pag-access sa labas ng isang API key, at ang mga tuntunin ng Gemini CLI ng Google ay nagsasabi na ang pag-sign-in nito ay maaaring hindi gamitin sa mga tool ng third-party.
  • Suriin ang mga tuntunin ng iyong plano at rehiyon bago mo ito idagdag. Kung mahalaga sa iyo ang isang account, ang API key ng provider ay ang mas ligtas na ruta.
  • Panatilihing naka-off ang access sa network sa pampublikong Wi-Fi, at huwag ipasa ang port 8327 sa internet. Ang API key ay hindi internet-grade security.

Ikonekta ang WebBrain sa Kasama

Ang WebBrain Companion ay libreng software sa ilalim ng lisensyang GPL-3.0-or-later at naka-embed ng CLIProxyAPI. Hindi ito kaakibat sa Anthropic, OpenAI, Google, xAI, Moonshot AI, Meta o Cognition.
