WebBrain for websites

Add an AI guide to your website.

Paste one line of code and every visitor can ask about the page they're on. WebBrain reads the page, answers from it, and, if you allow it, fills in forms and clicks through for them.

Free No credit card. Nothing for visitors to install. Try the live demoThe dashboard opens soon.

Embed code

Paste it before </body>.

embed.js · data-site-id
index.html 
<!-- WebBrain for websites -->
<script src="{{sites_dashboard_url}}/embed.js"
        data-site-id="site_your_id"
        defer></script>

<!-- That's it. The launcher appears in the
     corner, styled the way you set it up. -->
<!-- Any element can ask a question -->
<button data-webbrain-ask="Compare these plans for a team of 5">
  Which plan fits me?
</button>

<!-- Or let WebBrain act, when Ask + Act is on -->
<button data-webbrain-act="Fill in the demo request form">
  Fill it in for me
</button>
// Open the assistant from your own UI
WebBrain.open();

// Ask about the current page
WebBrain.ask('Summarize this page in 3 points');

// Let it act (sites with Ask + Act enabled)
WebBrain.act('Add the annual plan to my cart');

// Pick up dashboard changes without a reload
WebBrain.reloadConfig();

Google and X do it.
Your website can, too.

They put AI right where people are already reading and working. Give your visitors that same kind of help, built into your own website.

Now bring it to your website.

Help readers understand an article, shoppers choose a product, or customers complete a form. WebBrain for Websites adds an AI guide to the site you already have, with actions only when you enable them.

See how to add it

Live on your site in three steps.

No SDK to install and no build step. WebBrain loads after your page does and stays out of your styles.

  1. Add your site

    Enter your site's address in the dashboard. You get a site ID and your script tag right away.

  2. Paste one line

    Put the script before </body>. Anything that lets you add a script tag works: static sites, CMS themes, and single-page apps.

  3. Visitors ask

    A launcher appears in the corner. Visitors ask about the page they're on, and WebBrain answers from what's actually there.

You decide what it can do.

Every setting lives in the dashboard and reaches your site the moment you save. Visitors never see a key, a model picker, or a setup screen.

Ask, or Ask and Act

Keep WebBrain read-only, or let it type, tick boxes, and click buttons for the visitor, with a visible glow and a Stop button while it works. The server enforces your choice.

Your model, your key

Use any OpenAI-compatible endpoint: OpenAI, OpenRouter, Groq, DeepSeek, Gemini, Together AI, xAI, or your own server. Keys stay on the server.

Starter questions

Put one-click questions in the drawer, like “Summarize this page” or “Compare the plans,” so visitors know what to ask.

Buttons in your page

Turn any element into a question with data-webbrain-ask, or add “Explain this” buttons to every matching section with a CSS selector.

Highlight to ask

When a visitor selects text, a small pill offers to explain exactly that passage.

Your look

Light, dark, or matching the visitor's system. Choose the launcher style, icon, label, accent color, and corner.

A few things worth knowing.

What WebBrain sees, what it can do, and what it costs.

Is it really free?
Yes. The dashboard, the script, and the assistant your visitors use cost nothing. Paid tiers with extra features will come later for those who want them.
What does WebBrain see on my site?
The page the visitor has open, read as an accessibility tree (the same structure screen readers use), plus the visitor's question. That goes to WebBrain's server and on to the model configured for your site. API keys stay on the server and never reach the browser.
Can it change anything on my site?
Only if you allow it. In Ask mode WebBrain reads and answers. In Ask + Act mode it can type into fields, tick boxes, click buttons, and scroll, with a visible glow, cursor, and Stop button. Everything happens in the visitor's own tab, on their behalf; it can't touch your site's code.
Which AI models can I use?
Any OpenAI-compatible endpoint: OpenAI, OpenRouter, Groq, DeepSeek, Google Gemini, Together AI, xAI, or your own OpenAI-compatible server. Set it once in the dashboard; visitors never see a key or a model picker.
Will it work on my site?
If you can add a script tag before </body>, yes: static sites, CMS themes, and single-page apps alike. The assistant draws itself in its own shadow DOM, so your styles and its styles don't collide.
How is this different from the WebBrain extension?
The browser extension helps you on any site you visit. WebBrain for websites helps your visitors on your site, and they don't need to install anything. Both are built on the same open-source WebBrain engine.
